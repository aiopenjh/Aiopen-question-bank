# Celueste 마무리 구현·검증 기록 — 2026-09-14

## 사용자 의도와 구현 범위

본인 API를 연결해 임의 주제를 공부하고, 문제·답안·채점 결과를 저장하며, 아침·저녁 알림으로 수시로 공부하는 Android 우선 개인 학습 앱이다. 자동화는 학습 기록 보존과 알림 예약에 적용한다. 사용자가 요청하지 않은 유료 출제·다른 모델 재시도는 하지 않는다.

내부 출제 기준은 사용자가 정한 Gemini 3.5 이상이다. 2026-09-14 마무리 중 이를 2.5 기본값과 다중 공급자 선택 화면으로 변경한 잘못을 발견해 복구했다. 화면에는 모델명·공급자명을 별도 상태로 노출하지 않고 키 등록 상태만 표시한다. 이전 빌드가 남긴 낮은 모델 설정은 실행 시 3.5 기준으로 올리며 낮은 모델로 자동 전환하지 않는다.

이번 변경은 기존 화면·상태 구조를 유지한 마무리 수정이다. 기존 사용자 변경(자료함/설정 컴포넌트 분리, 대기 모달, 실행 스크립트)은 보존했다. Git 커밋·푸시·클라우드 배포는 하지 않았다.

## 검증

### 실행한 검사

- TypeScript `--noEmit`: 통과.
- 자동 테스트: 출제/모의 API, 키 보관, 저장/복원, 알림 예약 및 통합 학습 흐름 36개 통과.
- Expo 웹 프로덕션 번들: 생성 성공.
- 실제 인앱 브라우저·별도 localhost(4173) 합성 자료 사용:
  - 매일 학습 선택 → 알림 대상 7일 표시 → 새로고침 후 유지.
  - 합성 백업 2문제 복원 → API 키 없이 문제 풀기.
  - 1번 답 선택·2번 이동 → 새로고침 → 2번 위치와 1번 답안/보기 순서 보존.
  - 정답/오답 제출 → 50점 결과 → 새로고침 후 2문항 풀이·오답 1개 유지.
  - API 키 없는 출제 → 키 필요 안내·입력 문장 유지.
- 실제 API 키·회원 자료는 테스트에 사용하지 않았다. 유료 API 호출·실제 알림 발송은 하지 않았다.

### APK

APK 생성은 이번 수정·검증 범위로 요청받지 않았다. 잘못 시작한 로컬 빌드는 즉시 중단했으며, 그 과정에서 만든 `.build-tools`, 네이티브 `android` 폴더, `eas.json`, APK 전용 앱 식별자 설정을 제거했다. APK 파일은 생성하거나 전달하지 않았다.

### 남은 검증과 제한

1. 실제 Android 설치·실행, 앱 종료/복귀, 키 재실행 보관, 알림 권한 허용/거절, 08시/20시 수신, 절전·방해금지, 알림 탭 진입은 아직 실제 기기에서 확인하지 않았다.
2. 실제 개인 API의 모델 접근·응답 품질·요금/한도는 미검증이다. 키 등록을 연결 완료라고 표시하지 않는다.
3. AI 사실 정확성·오답 해설의 교육적 타당성은 형식 검사와 별도다. 공식 인증·무환각을 보장하지 않는다.
4. PDF/DOCX/PPTX 직접 읽기, 웹 본문 수집·검색, 자동 선수개념 재출제는 현재 활성 흐름에 없다. 텍스트 붙여넣기와 기존 오답 재풀이를 지원한다.
5. 기기간 자동 동기화와 클라우드 백업은 없다. API 키는 백업 제외이므로 새 기기에서 재등록한다.
6. 자유 요일 직접 선택은 아직 UI가 없으므로 월수금/평일/주말/매일 네 가지 실제 작동하는 선택지만 제공한다. 시간은 08:00/20:00이다.
7. `npm audit` 중간 위험 11개는 uuid 단일 advisory의 의존성 전파이다. 설치된 개발 도구 호출은 버퍼 없는 v4 경로이고 앱 소스는 직접 호출하지 않는다. 현재 취약 호출 경로는 발견하지 못했으나 의존성 경고 자체가 해결된 것은 아니다. 무검증 Expo 다운그레이드/강제 수정은 하지 않았다.

## 휴대폰 확인 순서

향후 APK 제작을 별도로 요청받은 뒤: APK 설치 → API 키 등록 → 새 주제 3문제 출제 → 1문제 답 선택 후 앱 종료·재실행 → 이어 풀어 제출 → 오답 재풀이 → 비행기 모드에서 저장 문제 풀기 → 백업 보관 → 알림 권한 허용과 예약 상태 확인 → 아침/저녁 실제 수신과 알림 진입 확인. 앱 업데이트는 같은 패키지·서명으로 설치하여 기록 유지 여부를 확인한다. 앱 삭제는 업데이트 시험 방법이 아니다.
