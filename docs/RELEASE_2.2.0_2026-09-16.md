# Celueste v2.2.0 릴리스 기록 — 2026-09-16

## 저장 구조

- 웹 학습 데이터를 `localStorage` 용량에 묶이지 않는 IndexedDB로 전환했다.
- 기존 사용자는 같은 브라우저와 주소에서 앱을 열면 과목·단원·문제·풀이 기록이 자동 이관된다.
- 이관 값 검증이 끝나기 전에는 IndexedDB 전환을 완료 처리하지 않으며, 실패하면 기존 저장소를 유지한다.
- API 키와 구형 보안 저장 키는 일반 학습 DB로 이관하지 않는다.
- 네이티브 Android·iOS는 기존 AsyncStorage와 OS 보안 저장소를 유지한다.

## 데이터 삭제와 안내

- 전체 데이터 초기화 시 IndexedDB, 이전 Celueste 저장 데이터와 API 키를 함께 삭제한다.
- 초기화 팝업과 공식 이용 가이드에 복구 불가 및 사전 백업 권장 문구를 추가했다.
- 홈 화면 아이콘만 삭제하면 데이터 삭제가 보장되지 않는다는 점과 사이트 데이터 수동 삭제 방법을 안내한다.

## 화면과 학습 흐름

- 새 과목 시작 영역, 응원 문구, 상단 헤더와 자료함 탐색 구조를 실사용 흐름에 맞게 정리했다.
- 문제 보관함을 과목 상세와 분리하고, 최초 출제와 추가 출제의 난이도 동작을 구분했다.

## 검증

- TypeScript `--noEmit` 검사
- 자동 회귀 테스트 32개
- IndexedDB 자동 이관, 보안 키 제외, 읽기·쓰기·삭제·전체 초기화 테스트

## 버전

- 앱 버전: `2.2.0`
- Android `versionCode`: `4`
