## 사용자 제안과 제품 방향

- 핵심 가치는 사용자가 정한 시간에 알람을 받고 바로 문제를 푸는 개인 학습 흐름이다.
- 서버가 사용자의 학습 데이터에 관여하지 않는 로컬 퍼스트 개인 문제집이어야 한다.
- 과목, 단원, 문제, 오답, 일정, 백업과 복원 기능은 UI 정리 과정에서도 상실되면 안 된다.
- 직접 고른 문제만 `나만의 오답노트`에 저장한다. 자동 오답 목록과 같은 의미로 중복 노출하지 않는다.
- 백업 ZIP은 앱 전체 데이터를 복원할 수 있어야 하며 API 키는 제외한다.
- 백업물은 단순 TXT가 아니라 나중에 출력하여 들고 다닐 수 있는 실제 문제지·오답노트 형태를 지향한다.
- 고등학생부터 성인까지 사용할 수 있도록 전문적이고 세련되되, 차갑지 않은 아기자기함을 유지한다.
- 배경은 연분홍 블러시 파스텔, 내부는 저대비 아이보리·라벤더·민트 보조색을 사용한다.
- 캐릭터는 유아풍이 아닌 청소년 후반·대학생 감성의 자연스러운 학습 안내자여야 한다.
- 반복 작업은 공통 토큰과 워크플로로 정리하고 `App.tsx`에 기능을 몰아넣지 않는다.

## 이번 브랜치에서 반영한 내용

### 화면과 디자인

- 전역 블러시 핑크 파스텔 배경과 공통 색상·간격·곡률 토큰을 도입했다.
- 메인, 자료함, 설정, 시험장과 주요 팝업을 같은 시각 언어로 정리했다.
- 팝업 닫기·버튼 입력을 앱 내부 모달 흐름에 다시 연결했다.
- 홈의 핵심 동선을 `복습 예정 / 나만의 오답노트 / 과목 자료함`으로 단순화했다.
- `나만의 오답노트`는 캐릭터를 포함한 중앙 강조 동선으로 배치했다.
- 앱 아이콘, Android 적응형 아이콘, 네 가지 상태 일러스트를 로컬 자산으로 추가했다.

### 정보 구조와 중복 제거

- 자료함의 `과목·목차 / 문제 보관함` 왕복 전환을 제거하고 한 화면의 연속 구조로 합쳤다.
- 상단 `자료함 3`처럼 의미가 불분명한 숫자를 제거했다.
- 과목 삭제는 주 행동 옆이 아니라 과목 카드 하단 관리 영역으로 이동했다.
- `오답 복습`, `오답 개념을 단단하게`, `나만의 오답노트`의 겹치는 의미를 정리했다.
- 직접 저장은 `나만의 오답노트`, 실제 틀린 문제의 보강은 시험 결과의 개념 보강 흐름으로 분리했다.
- 문제 보관함은 `전체 문제 → 과목 → 단원 → 문제`의 세로형 계층으로 변경했다.
  - `전체 문제`는 최상단에 유지한다.
  - 과목은 한 줄짜리 상위 탭으로 세로 배치한다.
  - 과목을 눌러야 하위 단원 탭이 나타난다.
  - 단원을 눌러야 해당 문제들이 나타난다.
  - 문제 카드의 해설, 직접 저장, 삭제 기능은 유지한다.

### 기능 보존과 안정화

- 생성 파이프라인과 훅이 같은 문제를 이중 저장하던 경로를 제거했다.
- 저장소 계층에서도 같은 ID 또는 같은 과목·단원의 정규화된 동일 지문을 중복 저장하지 않도록 방어했다.
- 알람으로 진입하면 해당 일정의 과목명이 오늘의 학습 영역에 반영되는 경로를 유지했다.
- Expo Go에서도 로컬 알림 예약 흐름을 사용할 수 있도록 불필요한 실행 차단을 제거했다.
- API 키는 네이티브에서 SecureStore를 사용하고, 웹 저장 경로도 기존 평문·단순 난독화보다 강화했다.
- 백업 ZIP 스키마를 확장해 앱 데이터를 복원하면서 API 키는 포함하지 않도록 했다.
- 출력용 문제지·오답노트 문서를 생성할 수 있는 내보내기 경로를 추가했다.

## 검증 상태

- `cd apps/mobile && npx tsc --noEmit`: 통과
- 실행 중인 Expo 웹 개발 서버 재번들: 통과 (`Web Bundled`)
- 배포: 수행하지 않음
- `main`, `gh-pages`: 변경하거나 푸시하지 않음
- 전체 자동 테스트: 수행 완료 상태로 간주하면 안 됨. 기존 테스트 설정에는 현재 저장소 구조와 맞지 않는 오래된 mock/경로 문제가 있다.
- 다음 세션에서 `run_mobile.bat`로 실제 휴대폰 Expo Go 확인이 필요하다.

개발 서버의 `version.json` 확인 경고와 React Native Web의 deprecated style 경고는 개발 환경 경고로 남아 있다. 이번 변경의 런타임 번들 오류는 확인되지 않았다.

## 다음 세션에서 우선 확인할 것

1. 문제 보관함에서 초기 상태가 접혀 있는지 확인한다.
2. `전체 문제`를 누르면 과목명이 붙은 단원들이 나타나는지 확인한다.
3. `Python 비동기 프로그래밍` 과목을 누르면 해당 과목의 단원만 바로 아래에 나타나는지 확인한다.
4. 단원을 누르면 그 단원의 3문제가 한 번씩만 나타나는지 확인한다.
5. 문제의 오답노트 저장, 해설 열기, 삭제가 기존처럼 동작하는지 확인한다.
6. 새 과목·문제 생성 후 중복 저장이 재발하지 않는지 확인한다.
7. 알람을 실제 예약하여 알림 탭 진입 시 선택된 과목명이 표시되는지 확인한다.
8. ZIP 백업 후 새 환경에서 복원하고, API 키가 복원되지 않는지 확인한다.
