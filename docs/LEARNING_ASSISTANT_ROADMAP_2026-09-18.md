# 문제은행 확장 및 개인 학습 비서 계획

- 작성일: 2026-09-18
- 상태: 대화 기반 계획 보관. 구현·서비스 도입·배포 승인을 의미하지 않음.
- 목적: 주관식 확장부터 개인 학습 비서와 정식 배포까지의 방향을 다음 논의에서 이어가기 위함.
- 다음 논의의 시작점: 아래 1단계 변경 설계와 첫 개선 묶음의 범위 확정.

## 1. 현재 출발점

사용자 설명에 따르면 수업 참여자들이 이미 서비스를 사용했으며, 편리하다는 반응과 주관식 기능 추가 요청을 주었다. 이번 계획은 수요가 확인되지 않은 아이디어의 재검증이 아니라, 실제 사용자 피드백에 따른 확장이다.

수업 참여자 대상의 편의성은 확인되었지만, 전국민 대상 수요·결제 의향·대규모 운영비까지 확인된 것은 아니다. 기존 사용자 개선과 대중 배포 준비를 구분한다.

## 2. 제품 방향

**실사용 검증을 마친 수업용 문제은행을 주관식과 개인 학습 비서 기능으로 발전시킨다.**

- 다양한 주제와 AI 맞춤 출제를 유지한다. 고정 문제은행으로 대체하지 않는다.
- 질문 → 설명 → 이해 확인 문제 → 답안 피드백 → 다음 학습으로 연결한다.
- 사용자가 지난 학습 상황을 매번 설명하지 않아도 학습을 이어갈 수 있게 한다.
- 기존 과목·단원·자료·객관식·문제 보관·복습 기능과 사용자 데이터를 최대한 보존한다.
- 현재 구조 검토만으로 전면 재개발이 더 빠르다고 판단할 근거는 없다. 필요한 흐름을 단계적으로 확장한다.
- 초기 개선 대상은 현재 수업 참여자다. 주제의 자유도와 서비스의 초기 대상 범위를 구분한다.

## 3. 시행 순서

| 단계 | 작업 | 완료 판단 기준 |
| --- | --- | --- |
| 1. 변경 설계 확정 | 문제 유형·입력 답안·평가 기준·부분점수·채점 상태와 기존 데이터 호환 설계 | 객관식을 보존하면서 새 유형을 추가할 변경 범위와 계약 확정 |
| 2. 기본 입력형 | 단답형·빈칸형·숫자형 및 해설·오답노트·복습·내보내기 연결 | 출제부터 풀이·채점·저장까지 사용 가능 |
| 3. 짧은 서술형 | 의미·조건·근거 평가, 대안 답안·부분점수·재검토 흐름 | 다른 표현의 정답을 인정하고 평가 이유를 표시 |
| 4. 수업 참여자 재사용 확인 | 입력형·서술형 사용 후 오채점·입력 불편·대기 시간 확인 및 범위 내 개선 | 주요 문제를 수정하고 수업에서 계속 사용 가능 |
| 5. 개인 학습 비서 | 개념별 학습 상태·복습·보충 문제·다음 단계와 추천 이유 | 기록을 활용하여 다음 학습을 이어주고 사용자가 추천을 선택·수정 가능 |
| 6. 대중 배포 기반 | 운영자 AI 연결 서버·사용량 한도·계정·DB·개인정보·약관·권리 정리 | API 키 없이 사용하며 운영비와 데이터 접근을 관리 가능 |
| 7. 정식 앱과 공식 랭킹 | 앱 배포 검증·스토어 등록, 공통 시험 서버 채점·랭킹 | 배포 조건과 점수 신뢰성을 충족 |

**첫 개선 묶음은 1~4단계다. 서버 전환이나 전면 재개발부터 시작하지 않는다.**

기간과 비용은 아직 산정하지 않았다. 단계별 범위와 검증 방법을 정한 후 판단한다. AI 이용 연령·자료 이용 권한 등 서비스 적용 조건은 해당 사용자와 기능에 제공하기 전에 확인한다.

## 4. 문제 유형과 채점 원칙

- 단답형: 인정 답안과 문항별 공백·대소문자 처리 규칙을 사용한다.
- 빈칸형: 빈칸별 정답·배점을 저장한다. 자연스럽게 여러 답이 가능하면 인정 답안을 넓히거나 지문을 고친다.
- 숫자형: 수치·단위·허용 오차·허용 입력 표기를 명시한다.
- 서술형: 모범답안과 문자열 일치가 아니라 질문 조건과 평가 항목 충족 여부를 평가한다.
- 영어·한문: 철자·글자 정확성이 목적인지, 의미·번역이 목적인지 구분한다.
- 개발·게임·AI 설계 문제: 기술적 타당성, 조건 충족, 근거, 가정·한계, 필요한 검증 방법을 문항에 맞게 평가한다. 모범답안 밖의 타당한 해법도 인정한다.
- 평가 기준과 배점은 출제 시 저장하며, 답안을 본 뒤 임의로 바꾸지 않는다. 변경이 필요하면 버전과 재평가 이력을 구분한다.
- 평가 근거는 학생 답안의 어느 부분을 인정했는지, 무엇이 부족한지를 보여준다. AI 확신도만으로 정답을 확정하지 않는다.
- 코드 실행을 하지 않았다면 실행 검증을 했다고 표현하지 않는다. 코드 실행 채점은 별도 범위다.

## 5. 모호함과 채점 실패 처리

- 의미와 조건을 충족하면 표현이 달라도 정답으로 인정한다.
- 일부 기준만 충족하면 해당 항목에 부분점수를 부여한다.
- 특정 조건에서만 타당하면 필요한 조건을 설명한다. 조건 명시가 평가 항목인 경우에만 그 기준에 따라 감점한다.
- 중요한 설명이 빠지면 현재 평가와 짧은 추가 질문을 제공하고, 답 보충 또는 해설 확인 후 다음 문제로 진행할 수 있게 한다.
- 문제 자체의 정보 부족·오류는 학생 오답으로 처리하지 않는다. 점수 계산과 오답 복습 대상에서 제외하고 설명 또는 대체 문제를 제공한다.
- 통신 실패는 답안을 보존하고 자동채점 미완료로 표시한다. 저장된 해설·기준을 볼 수 있게 하며 계속 학습할 수 있게 한다.
- 재검토 횟수와 대기 시간을 제한한다. 최종 AI 결과의 즉시 반환을 보장하지 않는다.
- 해설을 본 뒤 보충한 답안은 최초 평가와 분리한 복습 기록으로 남긴다.

## 6. 넓은 궁금증을 학습으로 연결

‘운동 잘하는 법’, ‘연차 잘 쓰는 법’, ‘게임 잘하는 법’도 정상 학습 주제로 받는다. 특정 목표나 개인 원인을 임의로 확정하지 않는다.

1. 가능한 학습 방향을 짧게 제시한다.
2. 선택하지 않아도 ‘전체부터 알아보기’로 시작할 수 있게 한다.
3. 확인된 사실은 객관식·빈칸형으로, 조건부 방법은 조건이 있는 상황형으로 만든다.
4. 취향·목표·실천 계획은 점수 없는 자기 점검으로 구분한다.
5. 근거가 부족한 내용을 억지로 정답으로 만들지 않고 설명·비교로 제공한다.

‘설명만 보기 / 문제로 익히기 / 내 상황에 적용하기’는 제안된 화면 방향이며, 구체적인 UI는 별도 설계한다.

## 7. 개인 학습 비서

- 앱이 목표·배운 개념·최근 성과·반복 오류를 저장하고 관련 요약만 AI에 전달한다. 모델이 자동으로 사용자를 기억한다고 가정하지 않는다.
- 전체 정답률뿐 아니라 새 문제에서의 성과, 힌트 사용, 재시도, 시간이 지난 뒤의 이해를 함께 고려한다. 새로 필요한 기록은 별도 추가한다.
- 적은 답안으로 숙련도나 고정된 학습 성향을 단정하지 않는다. 추천 이유를 설명하고 사용자 선택권을 둔다.
- 재사용이 허용된 검증 문제를 우선 선택하고, 부족한 부분은 AI로 맞춤 생성한다.
- 첫 기능 후보는 ‘오늘의 추천 문제 + 추천 이유 + 학습 후 다음 단계’다.
- 차별성은 단순 출제가 아니라 공부 준비 부담 감소와 학습의 지속성이다. 재방문·추천 만족도·새 문제 성과와 사용자당 비용으로 확인한다.

## 8. 운영·저장·랭킹·정식 배포

- 운영비 발생과 사용자 유료화는 별개다. 실제 비용을 측정한 뒤 무료 한도와 유료 기능 여부를 결정한다.
- 대중 배포에서는 운영자 API 키를 앱에 넣지 않고 서버에서 관리한다. 기존 로컬 중심 정책 변경은 별도 승인 범위다.
- 재사용이 허용된 문제·정답·해설·출처·검수 상태·버전은 DB에 보관하고 캐시는 속도 개선용으로 사용한다.
- 개인 업로드 자료와 개인 생성 문제는 공용 문제은행에 자동 편입하지 않는다. 사용자별 접근과 보관·삭제 정책을 설계한다.
- Google 검색 연동 결과는 캐싱·재사용 약관 제한을 확인해야 한다. 무조건 공용 DB에 축적하는 설계를 전제로 하지 않는다.
- 공식 랭킹은 검증된 공통 시험별로 시작한다. 서버가 배정·제출·채점을 관리하며, 앱이 보고하는 점수를 그대로 신뢰하지 않는다.
- 개인 맞춤 문제·서술형 점수는 초기 공식 랭킹에서 제외한다. 전 과목 난이도 보정과 완전한 부정행위 차단을 약속하지 않는다.
- 대상 연령과 AI 제공자 약관을 먼저 확인한다. 유료 API 전환만으로 연령 제한이 해결된다고 가정하지 않는다.
- 앱 자체 권리 정리, 외부 자료·이미지·의존성 라이선스, 개발자 계정 등록, 스토어 심사는 별개다.
- Android 배포 형식·서명·실기기 검증·개인정보 및 계정 삭제·해당 계정의 테스트 요구를 출시 시점에 다시 확인한다.

## 9. 초기 범위에서 제외하거나 뒤로 미룰 것

- 손글씨 인식과 풀이 사진 자동채점
- 모든 고급 수식·증명의 자동 판정
- 전 과목 통합 공식 랭킹
- 무제한 무료 AI 생성
- 기록이 적은 상태에서의 정밀한 개인 능력·성향 진단

수식 입력·미리보기·동치 판정은 기본 입력형과 서술형을 안정화한 후 지원 범위를 정해 별도 검토한다.

## 10. 다음 논의와 확인 상태
