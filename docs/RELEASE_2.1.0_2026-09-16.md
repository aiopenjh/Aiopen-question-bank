# Celueste v2.1.0 릴리스 기록 — 2026-09-16

## 변경 사항

- 자료함을 과목 목록과 과목 상세의 두 단계로 나눠 선택한 과목의 단원만 표시한다.
- 문제 보관함은 과목 상세 밖에서 전체 과목·단원을 통합 관리한다.
- 일일 학습 목표 입력과 저장 동선을 한 카드 안에서 간결하게 정리했다.
- 메인·자료함·설정 탭의 너비를 맞추고 화면 전환과 설정 화면 새로고침을 보강했다.
- 메인 화면의 중복 자료함 바로가기를 제거하고 복습 예정·나만의 오답노트에 집중했다.
- 공식 이용 가이드를 현재 과목·단원·문제 생성, 목표·알림, 백업 흐름에 맞게 갱신했다.
- 앱 이름 옆에 Celueste 책 아이콘을 표시하고 설치형 웹 아이콘 연결을 보강했다.
- AI 생성 대기창에 최적화된 네 장의 캐릭터 모션과 모션 감소 접근성 처리를 추가했다.
- 동일 생성 요청의 동시 실행을 하나의 공급자 호출로 합쳐 연속 입력과 429 위험을 줄였다.
- 전송·JSON 처리 예외 원문이 사용자 오류 메시지에 포함되지 않도록 차단했다.
- 오래된 생성·저장소·보안 저장소·알림·학습 파이프라인 테스트를 현재 아키텍처에 맞게 복구했다.
