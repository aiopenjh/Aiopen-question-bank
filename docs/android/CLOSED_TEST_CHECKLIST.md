# 성인 비공개 테스트 체크리스트

- 대상: 학원 성인 학습자(비공개 테스트 참여자만)
- 방식: 현재 구조 유지(사용자 API 키 연결, 문제·학습기록은 기기에만 저장)
- 기준 브랜치: `feature/android-app` (`d0b5652` 기준 작성)
- 범위 밖: 학생이 직접 쓰는 공개 출시 준비는 이 문서에서 다루지 않는다(맨 아래 목록만 기록).

결과 칸에는 `통과` / `실패` / `보류`와 짧은 메모를 적는다. 실패는 재현 순서와 기기·Android 버전·빌드 번호를 함께 남긴다. 실제 실행 결과는 이 파일을 수정하지 말고 `CLOSED_TEST_RUN_TEMPLATE.md`를 날짜별 파일로 복사해 기록한다.

## 0. 테스트 빌드 준비

- [ ] 빌드할 커밋을 기록했다. 작업 폴더의 미커밋 변경이 빌드에 들어가는지 확인하고, 넣을 변경은 먼저 커밋했다.
- [ ] 문제 신고(`879daef`), AI 데이터 전송 안내(`f4a4488`), 웹 랭킹 탈퇴 요청(`d0b5652`)이 빌드에 포함됐다. (`origin/main` 웹 배포와는 별개)
- [ ] 앱 화면 버전명(`src/constants/buildInfo.ts`)과 `app.json`의 `version`이 같다.
- [ ] Android `versionCode`가 업데이트 대상 설치본보다 크다. 기존 앱 위에 덮어 설치하려면 `applicationId`와 서명 인증서도 기존 앱과 같아야 한다.
- [ ] 배포 경로(APK 직접 설치 / Play 테스트 트랙)를 기록했다. Play 출시 때의 업데이트까지 검증하려면 가능하면 Play 테스트 트랙으로 설치·업데이트를 확인한다.
- [ ] EAS는 원격 버전 관리(`appVersionSource: remote`)이고 `production`만 자동 증가하므로, `preview` 빌드의 `versionCode`를 별도로 확인·기록했다.
- [ ] 내부 테스트는 `preview` 프로필 APK로 한다. 공개 배포용 AAB(`production`)는 별도 단계로 둔다.
- [ ] `expo-crypto`가 포함된 새 네이티브 빌드다(개발 빌드 재생성 포함).

## 4. AI 전송 안내·출제·채점

| ID | 확인 항목 | 기대 결과 | 결과 |
|---|---|---|---|
| A1 | 설치 후 첫 AI 요청(출제·채점·힌트 중 무엇이든) | 요청 전에 전송 안내가 한 번 뜬다 | |
| A2 | 안내에서 `취소` 또는 뒤로가기 | AI 요청이 전송되지 않는다(제공자 콘솔의 요청 수가 늘지 않음). 출제는 취소 안내, 채점은 채점 미완료로 남는다 | |
| A3 | 안내에서 `계속하기` 후 다음 요청 | 원래 요청이 진행되고, 이후에는 안내가 다시 뜨지 않는다 | |
| A4 | 여러 문항 주관식 채점을 처음 할 때 | 안내가 한 번만 뜬다 | |
| A5 | 객관식·단답형·서술형·빈칸형 채점 | 점수와 정오 표시가 맞다 | |
| A6 | API 키 미등록 상태에서 AI 기능 선택 | 연결 방법을 안내하고, 저장된 문제와 학습 기록은 계속 이용할 수 있다 | |
| A7 | API 키 교체·삭제 후 요청 | 새 키만 사용되고, 삭제한 키로 요청하지 않는다 | |
| A8 | 전체 백업·문제 신고·오류 기록 확인 | API 키 원문이 포함되지 않는다 | |
| A9 | 인터넷이 없는 상태에서 저장된 문제·학습 기록 열기 | 기존 로컬 데이터는 정상적으로 조회·풀이할 수 있다 | |

## 9. 품질 기록

- 문제 오류·신고 건수와 유형(사실 오류, 정답 문제, 모호함, 표시 오류, 부적절한 내용)
- 채점 이의(사용자 정정) 건수
- 가장 많이 막힌 화면과 이유
- 이 기록은 학생 공개 출시를 판단하는 근거로 쓴다.

## 범위 밖: 학생 공개 출시 전에 결정할 것

- AI 제공자와 호출 방식(Gemini API 약관의 18세 이상·미성년자 접근 앱 제한 검토)

- 회사 관리 호출 경로가 필요한지, 서버·비용·안전장치
- 개인정보 처리방침·Play 데이터 안전성 확정, 공개 배포용 AAB
