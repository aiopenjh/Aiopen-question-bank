# Celueste v2.3.1

## 최신 정보 출제 보강

- 세율·세금·부동산 법과 정책·법령처럼 변경 가능성이 큰 주제는 문제 출제 시 Google 검색 근거 기능을 자동 사용한다.
- 대한민국 시간 기준일과 현재 시행 상태를 프롬프트에 고정한다.
- 국가법령정보센터, 국세청, 기획재정부, 국토교통부, 행정안전부 등 정부 공식 도메인만 문항 근거로 허용한다.
- 검색 근거가 없거나 공식 출처 URL 검증에 실패하면 문제를 저장하지 않는다.
- 출제된 문제에는 기준일, 공식 기관, 문서명과 원문 URL을 저장하며 풀이 결과·문제 보관함·오답노트에서 확인할 수 있다.
- PDF 연결 과목은 사용자가 선택한 PDF 범위를 우선하며 자동 웹 검색을 혼합하지 않는다.

## API 조건

- 최신 정보 확인 출제에는 Google 검색 근거 기능을 지원하는 Gemini 3.5 이상 API 키가 필요하다.
- 일반 주제 및 저장 문제 풀이는 기존 흐름을 유지한다.
