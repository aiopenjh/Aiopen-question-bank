# Celueste v2.0.0 릴리스 기록 — 2026-09-16

## 제품 방향

Celueste는 사용자가 자신의 API를 연결하고 자유로운 주제를 직접 정해 문제를 생성·저장·풀이하는 로컬 퍼스트 CBT 문제은행이다. 희귀하거나 예상하지 못한 주제도 입력 자체를 이유로 거부하지 않되, 무의미한 입력과 주제 충돌은 실제 학습 의도를 기준으로 처리한다.

정해 둔 아침·저녁 알림은 재방문을 돕는다. 알림을 눌러 앱에 들어온 뒤에는 사용자가 기존 과목과 단원 중 학습 대상을 직접 선택한다.

## v2.0.0 변경

- 4단계 난이도를 1~30 레벨로 세분화하고 31 이상 확장 경로를 추가했다.
- 과목 시작 레벨과 문제별 출제 레벨을 목차·프롬프트·저장 데이터에 연결했다.
- 정답률만으로 레벨이 자동 변경되지 않도록 사용자 선택권을 유지했다.
- Gemini 기본 모델을 3.5로 고정하고 3.5 미만 모델로의 자동 전환을 막았다.
- 모든 문제를 1~4번 4지선다로 검사하고 저장 문제와 신규 문제의 중복 방지를 보강했다.
- API 요청 취소, 무응답 안내, 429 재호출 대기 처리를 보강했다.
- 단원 삭제 시 연결 문제를 함께 삭제하고 실패 시 원상 복구하도록 저장 흐름을 정리했다.
- 전체 과목 삭제 동선을 긴 문제 목록 아래가 아닌 과목 카드 관리 영역으로 옮겼다.
- 알림 진입 시 특정 단원이나 문제를 자동 시작하지 않도록 했다.
- `App.tsx`, 모달 스타일, 기능별 스타일, 시험지 출력 유틸리티 등 500줄 이상 파일을 역할별 파일로 분리했다.
- Android/iOS 홈 화면 추가용 매니페스트와 아이콘을 추가했다.
- 웹 업데이트 확인용 `version.json`을 빌드·배포 과정에서 자동 생성하도록 했다.

## 사용자 문의

사용자 테스트용 별도 설문이나 의견 입력 기능은 앱에 추가하지 않는다. 기존 카카오톡 연결을 문의 창구로 사용한다.

## 검증

- TypeScript `--noEmit`: 통과
- Expo 공개 설정 확인: 앱 버전 2.0.0, Android versionCode 2, 앱/적응형 아이콘 경로 확인
- Expo 웹 프로덕션 export: 성공
- 배포 산출물 확인: `version.json`, `manifest.json`, `favicon.ico`, 192/512px 아이콘, Apple Touch 아이콘 포함
- 소스 파일 500줄 미만 확인
- PowerShell 배포 스크립트 구문 검사 통과
- `git diff --check` 통과
- 429 대기, 요청 취소, 단원 삭제 연쇄 처리와 실패 복구의 집중 검증 통과

## 실사용 확인 항목

- 실제 사용자 API 계정의 Gemini 3.5 이상 접근 가능 여부와 응답 품질
- Android/iOS 홈 화면 추가 후 아이콘 표시
- 브라우저 및 기기 절전 정책에 따른 아침·저녁 알림 수신
- 자유 주제별 레벨 간 난이도 체감과 문제 정확성
- 카카오톡 문의로 접수되는 불편사항과 재현 절차

APK 제작은 이 릴리스 작업에 포함하지 않았다.
