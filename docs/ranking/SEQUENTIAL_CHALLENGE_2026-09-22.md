## 보존 및 호환

- 기존 데이터 변환·삭제 및 DB 버전 변경 없음. Attempt에 선택 필드만 추가.
- 도전 메타데이터는 기존 attempts 백업에 포함되어 새 버전 앱에서 복원 가능.
- 문항 삭제 후에도 완료된 도전 기록으로 진도 유지. 구형 앱은 순차 도전 제한을 보장하지 않으므로 새 버전끼리 사용해야 함.
- 기존 난이도가 현재 해금보다 높으면 저장값을 자동 덮어쓰지 않고 출제 창에서 가능한 단계와 사유를 안내.
- 이미 서버에 올라간 예전 최고값은 서버가 MAX로 보관하여 낮아지지 않는다. 기존 서버 점수 정리/정책 버전 구분은 서버 결정 때 별도 승인 필요.
- 로컬 순차 제한은 일반 사용 흐름을 위한 규칙이며 데이터 변조를 검증하는 서버 부정행위 방지 기능은 아님.

### 해결된 오류 — GEN-ERROR-REDACTION

- 발견: 2026-09-22, `feature/ranking`의 출제 회귀 테스트.
- 재현: `generator.test.cjs`의 `transport and JSON decoder exceptions do not expose raw provider secrets`.
- 결과: 통신/JSON 해독 예외를 처리하는 경로 중 반환 오류 메시지에 테스트용 민감 문자열이 남음.
- 기준 코드 확인: 변경 전 `HEAD:apps/mobile/src/domain/generator.ts`를 메모리에서 로드해 동일 테스트 실패를 재현. 이번 순차 도전으로 새로 발생한 실패는 아님.
- 수정: 네트워크·SDK·JSON 해독 예외 원문을 사용자 메시지와 콘솔에서 제거. 앱이 직접 생성한 문항 검증 오류만 전용 오류 타입으로 전달하며, 취소·요청 제한은 고정 안내로 변환.
- 검증: 두 예외에 비밀 문자열을 주입해 사용자 메시지와 캡처한 로그 모두에 포함되지 않음을 확인.
- 상태: **해결됨 / 테스트 통과**. 실제 사용자 키 노출 사고를 확인했다는 뜻은 아니며, 테스트가 검출한 노출 가능 경로를 차단했다.
