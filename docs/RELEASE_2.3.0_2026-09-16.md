# Celueste v2.3.0

## 자료 기반 학습

- `+ 자료`에서 PDF, TXT, MD, CSV, JSON, ZIP 자료를 등록한다.
- `자료함 → 과목 추가 → 내 파일 불러오기`에서 자료를 선택하면 과목 ID와 자료 ID를 명시적으로 연결한다.
- 텍스트 자료는 연결된 본문만 첫 목차와 이후 문제 출제 근거로 사용한다.
- PDF는 기기에서 페이지 수를 확인하고 선택한 구간만 목차·문제 생성 요청에 첨부한다.
- PDF 원본, base64, 전체 추출 본문은 IndexedDB와 백업에 저장하지 않는다. 앱 재실행 뒤 PDF 출제가 필요하면 같은 원본을 다시 선택한다.

## API 사용 안내

- 한 번 출제 선택지는 3문항과 5문항으로 제한했다.
- 하루 누적 15문항을 권장 기준으로 두고, 이를 넘는 추가 생성 전에 무료 할당량 소진과 429 가능성을 안내한다.
- 30페이지가 넘는 PDF는 10~20페이지 구간으로 나누어 출제하도록 안내한다.

## 데이터 일관성

- 과목 삭제 시 해당 과목의 자료 연결도 함께 제거한다.
- 자료 삭제 시 자료 리비전, 텍스트 조각, 과목 연결을 함께 제거한다.
- 백업·복원에 과목과 자료의 연결 메타데이터를 포함한다.
