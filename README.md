# Celueste — 나만의 AI 학습 문제은행

Celueste는 배우고 싶은 주제와 난이도를 정하면 AI가 단계별 목차와 문제를 만들고, CBT 풀이·해설·오답 복습까지 이어주는 로컬 퍼스트 학습 서비스입니다. 시험 과목뿐 아니라 취미, 업무, 생활 속 궁금증과 엉뚱한 아이디어도 학습 주제로 사용할 수 있습니다.

- 웹 서비스: [Celueste 바로가기](https://aiopenjh.github.io/Aiopen-question-bank/)
- 개발자·관리자 문서: [DEVELOPER.md](DEVELOPER.md)
- 버전별 변경 이력: [CHANGELOG.md](CHANGELOG.md)
- 공통 개발 원칙: [AGENTS.md](AGENTS.md)

## 처음 사용하기 전에

Celueste가 실제 문제를 만들려면 사용자가 준비한 AI API 키가 필요합니다. Google Gemini, Anthropic Claude 또는 OpenAI 중 하나를 연결할 수 있습니다. 키가 없거나 통신에 실패하면 가짜 문제를 만들어 보여주지 않고 연결이 필요하다는 안내를 표시합니다.

학습 데이터는 기본적으로 현재 기기에 저장됩니다. 브라우저 데이터 삭제, 앱 초기화 또는 기기 변경 전에 반드시 백업 파일을 만들어 두세요.

## 10분 시작 순서

1. [웹 서비스](https://aiopenjh.github.io/Aiopen-question-bank/)를 엽니다.
2. `설정 → AI 연결`을 펼치고 본인의 API 키를 저장합니다.
3. 메인 중앙의 `배우고 싶은 주제를 자유롭게 입력하세요` 영역을 누릅니다.
4. 과목 이름과 시작 난이도를 정하고 `과목 만들기`를 누릅니다.
5. AI가 만든 첫 5개 단원 중 하나에서 `새 문제 만들기`를 누릅니다.
6. 3문제 또는 5문제를 골라 문제를 생성합니다.
7. CBT 시험을 제출하고 정답, 해설과 오답 원인을 확인합니다.
8. 계속 보관할 문제는 오답노트에 저장하고, 기기 변경 전에는 `설정 → 데이터 관리 → 백업`을 실행합니다.

## 단계별 사용 방법

### 1. AI 연결하기

1. 하단 탭에서 `설정`으로 이동합니다.
2. `AI 연결` 행을 눌러 내용을 펼칩니다.
3. Google Gemini, Anthropic Claude 또는 OpenAI 중 사용할 키를 입력하고 저장합니다.
4. 연결 상태가 표시되는지 확인합니다.

API 키는 일반 학습 데이터와 분리해 현재 기기에 보관합니다. ZIP·JSON 학습 백업에는 API 키가 포함되지 않으므로 새 기기에서는 다시 등록해야 합니다.

최신 세율, 법령, 부동산 정책처럼 바뀔 수 있는 주제는 공식 근거 검색을 지원하는 Gemini 연결이 필요할 수 있습니다. 공식 근거를 확인하지 못하면 임의로 문제를 만들지 않고 출제를 중단합니다.

### 2. 자유로운 학습 주제 만들기

1. 메인 중앙의 반투명 검색 영역을 누르거나 자료함 오른쪽 위의 `+ 과목 추가`를 누릅니다.
2. `과목 이름`에 배우고 싶은 내용을 입력합니다.
3. 필요하면 저장해 둔 자료를 `내 파일 불러오기`에서 연결합니다.
4. `과목 분류`는 직접 입력하거나 추천 분류를 선택합니다. 분류는 선택 사항입니다.
5. 시작 난이도를 정하고 `과목 만들기`를 누릅니다.
6. AI가 주제와 시작 난이도에 맞는 첫 5개 학습 단원을 구성할 때까지 기다립니다.

과목 이름은 정규 시험 과목으로 제한되지 않습니다. 다음처럼 성격이 전혀 다른 주제도 사용할 수 있습니다.

- 일반 학습: `Python 비동기 프로그래밍`, `회계 기초`, `여행 영어`
- 취미와 창작: `커피 로스팅`, `게임 세계관 만들기`, `반려견 행동 이해`
- 엉뚱한 아이디어: `바람 잘 피하기`, `불편하게 잠자기`

대주제와 세부 학습 대상이 다를 때는 더 구체적으로 입력한 세부 대상을 우선합니다. 의미 없는 자모나 장난 입력은 무시하고 정상적인 대주제 기준으로 목차와 문제를 구성합니다.

### 3. 교재와 자료 연결하기

1. 화면 상단의 `+ 자료`를 누릅니다.
2. 파일을 선택하거나 텍스트 자료를 직접 등록합니다.
3. 새 과목을 만들 때 `내 파일 불러오기`에서 등록한 자료를 선택합니다.
4. 연결된 자료가 있는 과목은 해당 본문과 용어를 우선 근거로 목차와 문제를 만듭니다.

지원 방식은 다음과 같습니다.

- `TXT`, `MD`, `CSV`, `JSON`: 본문을 읽어 저장하므로 반복 출제에 적합합니다.
- `ZIP`: 압축 안의 TXT, MD, CSV, JSON 텍스트 파일을 함께 불러옵니다.
- `PDF`: 선택한 페이지를 생성 요청에 전달합니다. PDF 직접 출제는 Gemini 연결에서 지원하며 원본과 전체 본문은 저장하지 않습니다.
- `HWP`, `HWPX`: 현재 본문을 직접 읽지 못합니다. 한글 프로그램에서 PDF 또는 TXT로 변환한 뒤 등록하세요.

30페이지가 넘는 PDF는 10~20페이지씩 나누고, 한 번에 3~5문항씩 만드는 것을 권장합니다. 앱을 다시 연 뒤 같은 PDF를 사용하려면 보안을 위해 원본 파일을 다시 선택해야 합니다.

### 4. 자료함과 단계별 목차 사용하기

1. `자료함` 탭에서 전체 또는 분류를 선택합니다.
2. 과목 카드를 눌러 해당 과목의 단원 목록을 엽니다.
3. 각 단원에서 보관 문항 수와 `기존 문제 풀기`, `새 문제 만들기`를 확인합니다.
4. 현재 단계를 학습한 뒤 `다음 5개 단원 생성`으로 목차를 확장합니다.

목차는 한꺼번에 길게 만들지 않고 5개 단위로 확장합니다. 30단원 이후에도 계속 추가할 수 있으며, 이미 존재하는 단원과 비슷한 이름은 중복되지 않도록 정리합니다.

### 5. 새 문제 만들기

1. 자료함에서 과목과 단원을 선택합니다.
2. `새 문제 만들기`를 누릅니다.
3. 첫 출제는 과목을 만들 때 정한 시작 레벨을 사용합니다.
4. 추가 출제에서는 해당 단원에 적용할 레벨을 바꿀 수 있습니다.
5. `3문제` 또는 `5문제`를 선택합니다.
6. 기존 문제가 있는 상태에서 레벨을 바꾸면 기존 문제 유지 또는 삭제 방식을 확인한 뒤 진행합니다.

`기존문제유지 + 레벨변경`은 이전 문제를 남기고 새 문제를 누적합니다. `기존문제삭제 + 레벨변경`은 새 문제 저장이 성공한 뒤 해당 단원의 이전 문제를 삭제합니다. 설정창을 닫거나 생성을 취소하면 선택한 레벨과 새 문제는 저장하지 않습니다.

난이도는 다음처럼 사용합니다.

- 레벨 1~10: 필수 용어와 핵심 차이
- 레벨 11~20: 기본 적용부터 응용 판단
- 레벨 21~30: 세부 조건, 오개념 판별과 종합 추론
- 레벨 31 이상: 새로운 사례와 관점으로 이어지는 순차 도전

레벨 31 이상 순차 도전은 매번 새로 생성한 3문제로 진행하며 2문제 이상 맞히면 다음 레벨이 열립니다. 저장된 문제를 다시 푸는 것은 복습 기록으로만 남고 순차 도전 통과와 초고난도 랭킹에는 반영되지 않습니다. 정답률만으로 일반 단원 레벨을 임의 변경하지 않습니다.

### 6. 저장된 문제 바로 풀기

단원에 문제가 저장되어 있으면 `기존 문제 풀기`를 눌러 AI 호출 없이 바로 시험을 시작할 수 있습니다. 레벨 31 이상 단원에서는 버튼이 `기존 문제 복습`으로 표시되며, 새 순차 도전은 `새 문제로 도전`에서 시작합니다. 과목 전체에 저장된 문제를 모아 전체 CBT로 풀 수도 있습니다.

문항 유형은 출제할 때 문항마다 독립적으로 결정됩니다.

- 객관식: 보기 중 하나를 선택합니다.
- 단답형: 짧은 답안을 직접 입력합니다.
- 서술형: 설명형 답안을 직접 작성합니다.
- 빈칸형: 표시된 각 빈칸에 답을 입력합니다.

문제 순서와 객관식 정답 위치는 코드에서 무작위로 분산합니다. 문제 지문, 보기와 답안 입력란은 모바일에서도 읽기 쉬운 기기 기본 한글 글꼴을 사용합니다.

### 7. 시험 제출과 해설 확인하기

1. 상단 문제 번호를 눌러 원하는 문항으로 이동합니다.
2. 필요한 경우 `풀이공간`을 열어 계산이나 메모를 작성합니다.
3. 마지막 문항에서 `최종 제출 및 채점`을 누릅니다.
4. 미답변 문항이 있으면 안내를 확인하고 다시 답하거나 제출을 계속합니다.
5. 제출 후 점수, 정답, 작성한 답안, 오답 원인, 핵심 개념과 해설을 확인합니다.

풀이공간의 필기는 답안이나 채점에 포함되지 않습니다. `↶ 되돌리기`는 마지막 한 획만 지우고 `전체 지우기`는 현재 그림을 모두 지웁니다. 다른 문제로 이동하면 풀이공간이 닫히고 그림이 초기화됩니다.

빈칸형은 기기에서 즉시 채점합니다. 단답형과 서술형은 연결된 AI가 모범답안과 채점 기준에 따라 판정합니다. AI 채점에 실패하면 사용자가 작성한 답안은 보존하지만 제공자 오류 원문은 저장하지 않습니다.

### 8. 복습 예정과 오답노트 사용하기

- 틀린 문제는 메인의 `복습 예정`에서 다시 풀 수 있습니다.
- 오래 보관할 문제는 문제 보관함에서 `오답노트 저장`을 누릅니다.
- 메인의 `나만의 오답노트`에서는 직접 고른 문제만 과목별로 모아 복습합니다.
- 저장된 힌트가 없는 문제는 `AI 힌트 만들기`를 눌렀을 때만 생성하며, 만들어진 힌트는 다시 사용할 수 있도록 저장합니다.

### 9. 선택형 랭킹 참여하기

1. 메인·자료함·설정 상단의 랭킹 버튼을 누릅니다.
2. 이전에 참여한 계정이 있다면 `백업 파일로 기존 계정 복구`를 누르고 랭킹 참여 후 저장한 JSON 또는 이전 ZIP 백업을 선택합니다. **랭킹 계정만 다시 연결하며 현재 과목·문제와 API 키는 바꾸지 않습니다.**
3. 처음 참여한다면 공개 닉네임 2~12자를 입력하고 `참여 등록`을 누릅니다.
4. 등록 이후에는 평소처럼 문제를 풀고 시험을 제출합니다.
5. 시험 완료 시 최다 문제 풀이, 꾸준함, 초고난도 도전 기록이 자동 연동됩니다.

하루 3문제 이상 완료하면 꾸준함 기록에 반영됩니다. 한 사용자가 세 랭킹에 동시에 표시될 수 있지만 다른 사용자가 사용 중인 닉네임은 중복 등록할 수 없습니다. 욕설, 성적 표현, 운영자 사칭어와 공백·기호를 이용한 우회 닉네임은 서버에서 거부합니다.

초고난도 기록은 레벨 31 도전부터 집계됩니다. 랭킹 화면의 `최고 난이도는 Lv.31부터! 지금 도전해 보세요 ⚔️` 안내에서 적용 기준을 확인할 수 있습니다.

문제 내용, 정답, 과목명과 개인 API 키는 랭킹 서버로 보내지 않습니다. 네트워크 연결이 실패하면 최신 기록을 기기에 대기시켰다가 다음 시험 완료 때 다시 전송합니다.

백업 파일에는 랭킹 계정 복구 정보가 포함될 수 있으므로 안전하게 보관하세요. 다른 브라우저·기기에서 새 닉네임을 등록하면 기존 계정과 기록이 분리됩니다. 가입자 본인 여부를 확인하는 로그인은 아직 없으므로, 기존 계정이 있다면 먼저 백업으로 복구하세요. 탈퇴 요청 시 닉네임은 랭킹에서 즉시 숨겨지고 3일 후 서버 기록이 삭제됩니다. 유예 기간 안에 복구하면 탈퇴 요청이 취소됩니다.

### 10. 목표와 알람 설정하기

1. `설정 → 학습 루틴`에서 일일 목표를 1~30문항 사이로 정합니다.
2. 숫자를 바꾸면 별도 저장 버튼 없이 메인 진행률에 즉시 반영됩니다.
3. 알람을 받을 공통 요일을 선택합니다.
4. `07:20`, `13:00`, `22:15`처럼 원하는 시간을 최대 8개까지 등록합니다.
5. 시간 카드를 누르면 수정하고 `×`를 누르면 개별 삭제합니다.

알림 권한이 허용되어야 하며, 웹 알림은 브라우저 실행 상태의 영향을 받습니다. 앱이나 웹페이지가 완전히 종료된 상태에서도 안정적인 예약 알림이 필요하면 모바일 네이티브 앱을 권장합니다.

### 11. 백업, 출력과 복원하기

백업하기:

1. `설정 → 데이터 관리`를 펼칩니다.
2. `학습 데이터 백업 → 백업`을 누릅니다.
3. 내려받은 JSON 파일을 안전한 위치에 보관합니다.

새 백업에는 과목, 단원, 저장된 문제와 랭킹 계정 복구 정보가 포함될 수 있습니다. 풀이 기록, 원본 교재, API 키는 포함되지 않습니다. 랭킹 복구 정보가 담긴 파일은 다른 사람과 공유하지 마세요.

문제집 PDF 저장하기:

1. `설정 → 데이터 관리 → 내 문제집 내보내기`에서 `문제집 만들기`를 누릅니다.
2. 원하는 과목을 하나 이상 선택하고, 필요할 때만 `정답과 해설 포함`을 켭니다.
3. `PDF 파일 바로 저장`을 누르면 인쇄 기능이 없는 브라우저에서도 A4 PDF를 내려받습니다. 이 방식은 글자가 이미지로 저장되어 텍스트 선택은 할 수 없습니다.
4. 저장 전에 배치를 보려면 `PDF 저장 화면 열기`를 누릅니다. 미리보기 오른쪽 위 `×`로 앱에 돌아올 수 있습니다. 브라우저 자체 인쇄 기능을 지원할 때만 브라우저 인쇄 메뉴에서 PDF로 저장할 수 있습니다.

문제집은 과목별로 선택한 단원을 각각 새 A4 페이지에 배치합니다. 문제 번호는 단원마다 1번부터 시작하고, 주관식 문항 아래에는 글이나 풀이를 적을 수 있는 빈 공간만 둡니다. 가운데 세로줄로 좌우 문제를 구분하며, 페이지 아래에는 `CELUESTE로 만든 나만의 문제집` 문구가 표시됩니다. `정답과 해설 포함`을 선택하면 해설지에도 단원별 번호가 적용됩니다. 과목명·문항 수·날짜·닉네임을 반복한 보조 줄은 표시하지 않습니다.

복원하기:

1. 새 기기에서 Celueste를 엽니다.
2. `설정 → 데이터 관리 → 복원`을 누릅니다.
3. 저장해 둔 JSON 파일을 선택합니다. 예전 ZIP 백업도 읽을 수 있습니다.
4. 파일 검사가 끝난 뒤 과목·단원·문제와 랭킹 복구 상태를 확인합니다. 복원은 현재 학습 데이터를 교체합니다.
5. API 키는 새 기기에서 다시 등록합니다.

전체 데이터 초기화는 과목, 단원, 문제, 풀이 기록과 등록한 API 키를 삭제합니다. 새 JSON 백업으로는 과목·단원·문제와 랭킹 복구 정보만 되살릴 수 있으므로 초기화 전에 필요한 기록을 확인하세요. 홈 화면 아이콘만 삭제하는 것으로는 브라우저 학습 데이터가 삭제되지 않습니다.

### 12. 홈 화면 설치와 앱 갱신하기

- Android Chrome: 브라우저 메뉴 → `홈 화면에 추가`
- iPhone Safari: 공유 메뉴 → `홈 화면에 추가`

새 버전 확인:

1. `설정` 화면 맨 아래에서 현재 버전을 확인합니다.
2. `갱신`을 눌러 서버의 최신 버전을 확인합니다.
3. 새 버전 안내가 나오면 화면 안내에 따라 다시 불러옵니다.
4. 이전 화면이 계속 보이면 브라우저를 완전히 닫았다가 다시 열거나 홈 화면 앱을 다시 실행합니다.

## 데이터 저장과 개인정보

- 웹 학습 데이터: 현재 브라우저의 IndexedDB
- 모바일 학습 데이터: 기기의 AsyncStorage
- API 키: 일반 학습 데이터와 분리된 기기 저장 영역
- 랭킹 데이터: 공개 닉네임, 날짜별 완료 문제 수, 연속 학습일, 최고 순차 통과 레벨과 인증용 토큰 해시

개인 학습 문제, 정답, 과목명, 교재 본문과 API 키는 랭킹 서버에 저장하지 않습니다. 브라우저 데이터 삭제나 전체 초기화 전에는 사용자가 직접 백업해야 합니다.

## 자주 발생하는 문제

### 문제를 만들 수 없다고 나옵니다

`설정 → AI 연결`에서 키가 등록되어 있는지 확인하세요. Gemini는 3.5 Flash부터 요청하며, 사용량 제한이나 일시적 서버 오류가 있으면 3.5 Flash-Lite → 3.6 Flash → 3.7 Flash → 3.8 Flash 순서로 시도합니다. 3.5 미만 모델은 사용하지 않습니다.

모델을 전환해도 429 오류가 계속되면 Google AI Studio에서 해당 키가 속한 프로젝트의 모델별 사용량을 확인하세요. 대기 후 재시도할 수 있지만, 일일 할당량 소진은 짧게 기다리는 것만으로 해결되지 않을 수 있습니다. 키를 교체하면 이전 키의 앱 내 대기 상태가 새 키를 막지 않습니다. 실패한 출제로 기존 문제와 학습 기록이 삭제되지는 않습니다.

### PDF 연결 과목에서 원본을 다시 선택하라고 합니다

PDF 원본과 전체 본문은 기기에 계속 저장하지 않습니다. 상단 `+ 자료`에서 같은 PDF를 다시 선택하세요.

### 랭킹 등록이 되지 않습니다

인터넷 연결을 확인하고 다른 사용자가 쓰지 않는 2~12자 닉네임을 입력하세요. 욕설, 성적 표현과 `관리자`, `운영자`, `admin` 같은 사칭 표현은 사용할 수 없습니다.

### 휴대폰에서 새 UI가 바로 보이지 않습니다

설정의 `갱신`에서 최신 버전을 확인한 뒤 앱을 다시 불러오세요. 홈 화면 앱이 이전 캐시를 계속 사용하면 브라우저를 완전히 종료한 후 다시 열어 주세요.

### 기기를 바꾸면 데이터가 자동으로 따라오나요?

기본 학습 데이터는 계정 서버가 아니라 현재 기기에 저장되므로 자동 이동하지 않습니다. 기존 기기에서 JSON 백업을 만든 뒤 새 기기에서 복원하세요. 이전 ZIP 백업도 계속 복원할 수 있습니다.
