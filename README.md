## 🌟 Celueste의 4대 핵심 특징

1. **💸 서버비 0원 & 무제한 출제**  
   Google AI Studio의 무료 API 키를 연동하여 평생 추가 비용 없이 원하는 과목의 4지선다 기출·실전 문제를 무제한으로 만들어 풀 수 있습니다.

2. **🔒 완벽한 프라이버시 (Local-First)**  
   외부 중앙 서버로 어떤 학습 데이터나 API 키도 전송되지 않습니다. 모든 과목, 문제, 오답 기록은 본인의 스마트폰/PC 로컬 브라우저에만 암호화 보관됩니다.

3. **🎯 4단계 입체 오답노트 & '복습의 집'**  
   단순한 정답 공개를 넘어 `오답 원인 분석` ➔ `핵심 학술 개념` ➔ `함정 방지 팁` ➔ `명쾌한 도출 과정`의 4단계 멘토링을 제공하며, 틀린 문제는 '복습의 집'에 모여 1초 만에 재시험을 치를 수 있습니다.

4. **📖 내 교재·요약본 맞춤 출제**  
   가지고 있는 수험서, 수업 필기, 핵심 요약 텍스트를 첨부하면 AI가 해당 교재의 전문 용어와 맥락을 최우선 반영하여 적중률 높은 실전 문제를 출제합니다.

## 📖 상세 사용설명서 (Comprehensive User Manual)

### 1️⃣ 1분 퀵스타트: 무료 Gemini API 키 발급 및 등록
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 접속하여 구글 계정으로 로그인합니다.
2. **[Create API key]** 버튼을 눌러 무료 API 키를 복사합니다. (신용카드 등록 없이 평생 무료 티어로 넉넉하게 이용 가능)
3. Celueste 우측 상단의 **⚙️ 설정** 아이콘을 누릅니다.
4. 발급받은 API 키를 입력란에 붙여넣고 **[저장]**을 누르면 모든 출제 준비가 끝납니다.
   > 🔒 **보안 보장**: 입력하신 API 키는 외부 중앙 서버로 전송되지 않으며, 오직 본인 기기 로컬 스토리지에만 암호화 보관됩니다. (OpenAI `sk-`, Claude `sk-ant-` 키도 호환 지원)

---

### 2️⃣ 나만의 학습 과목 추가 & 30단계 마이크로 목차 설계
1. 메인 화면 하단의 **[📚 과목자료함]** 탭으로 이동하거나 상단 버튼을 터치합니다.
2. **[+ 새 과목 추가]** 버튼을 누르고 과목 정보를 입력합니다:
   - **🏷️ 과목 이름 (대주제)**: 시험 과목이나 공부하고 싶은 주제 (예: `정보처리기사`, `법학개론`, `토익 보카`, `회계원리`, `한국사`, `바리스타 필기` 등)
   - **📂 과목 분류 (소주제/영역)**: 세부 학습 영역을 직접 입력하거나 하단 추천 칩(`⚖️ 법학`, `🎮 게임/개발`, `💼 비즈니스`, `🌐 어학` 등)을 터치합니다.
   - **🌱 학습자 난이도 수준 선택**:
     * 🐣 **입문 기초**: 해당 학문의 뼈대가 되는 필수 기본 개념과 정통 표준 용어부터 시작하는 정석 코스
     * 🌿 **기본 정규**: 표준 교과서 수준의 핵심 원리 중심 코스
     * 🚀 **실전 대비**: 뻔한 기초 개념은 건너뛰고, 실제 시험 빈출 함정 및 심화 기출부터 바로 파고드는 패스트트랙
     * 👑 **심화 킬러**: 변별력을 가르는 고난도 복합 추론 중심의 마스터 코스
3. **[과목 및 목차 자동 생성]**을 누르면, AI가 국가공인 표준 교육과정에 기반하여 **1단계(01~05단원) 마이크로 목차**를 5초 만에 자동으로 구축합니다.
   > 💡 **30단계 진도 확장**: 05단원까지 학습을 마친 후에는 과목자료함에서 **[🚀 다음 5단계 목차 생성]**을 눌러 10단원, 15단원... 최대 30단원까지 촘촘한 계단식 커리큘럼을 계속 이어나갈 수 있습니다.

---

### 3️⃣ [적중률 극대화] 내 수험서·필기 요약본 첨부 가이드
AI가 일반적인 지식이 아닌, **내가 실제로 시험 볼 교재의 전문 용어와 출제 맥락을 100% 반영**하게 만들 수 있습니다.

* **첨부 방법**:
  1. 과목자료함에서 해당 과목 카드 하단의 **[📖 교재/자료 첨부]**를 누릅니다.
  2. 내가 가진 수험서, 수업 요약 필기, PDF 텍스트 등을 복사하여 붙여넣고 저장합니다.
* **추천 파일 형식 및 팁**:
  * **텍스트(TXT), 마크다운(MD) (강력 추천 ⭐)**: 텍스트가 원본 그대로 AI에게 전달되어 문제 적중률이 가장 뛰어납니다.
  * **스마트폰에서 쉽게 넣기**: PC나 태블릿의 요약본을 **카카오톡 '나와의 채팅'**이나 **구글 드라이브**에 올려두면 스마트폰에서도 1초 만에 복사하여 붙여넣을 수 있습니다.
  * **한글 문서(.hwp, .hwpx) 주의**: 한글 전용 문서는 AI가 직접 읽을 수 없으므로, 한글 프로그램에서 `[파일 ➔ 다른 이름으로 저장 ➔ 텍스트 문서(.txt)]`로 변환 후 붙여넣어 주세요.

---

### 4️⃣ 실전 CBT 시험 응시 & 문항 수 선택
1. 과목자료함에서 풀고 싶은 단원의 **[문제 출제]** 버튼을 누릅니다.
2. 팝업에서 **[3문항]**, **[5문항]**, **[10문항]**, **[20문항]** 중 오늘 풀고 싶은 분량을 선택합니다.
3. 5~10초 만에 공인 시험 기준의 4지선다 문제가 출제되며 **실전 CBT 시험장**으로 즉시 입장합니다.
4. **시험 진행 기능**:
   - **실시간 타이머 & 진행 바**: 시험 시간 배분 훈련 및 문항별 마킹 상태를 한눈에 파악
   - **4지선다 마킹**: 자격증/국가고시 실전 시험장과 동일한 즉각적인 선지 선택 UI
   - **[시험 제출]**: 모든 문제를 풀고 제출하면 즉시 채점 결과와 점수가 공개됩니다.

---

### 5️⃣ 4단계 입체 오답노트 & '복습의 집' 정복
단순히 "정답은 3번입니다"로 끝나는 해설은 학습에 도움이 되지 않습니다. Celueste는 정교한 4단계 멘토링을 제공합니다:

1. ❌ **선택한 오답 집중 분석**: 학습자가 고른 보기가 왜 정답이 될 수 없으며, 어떤 출제자 함정에 빠진 것인지 정확히 지적
2. 📖 **핵심 개념 요약**: 문제의 근간이 되는 학술 이론과 반드시 암기해야 할 핵심 포인트
3. 🔍 **실전 함정 방지 팁**: 다음 시험에서 동일한 유형을 만났을 때 헷갈리지 않고 정답을 골라내는 판별 기준
4. 💡 **정답 및 도출 과정**: 완전무결한 정답 해설 및 논리적 추론 과정

* **⭐ 나만의 오답노트 찜하기**:
  * 해설을 보며 나중에 시험 직전에 다시 보고 싶은 문제는 상단의 **[☆ 기억하기]**를 터치하세요.
  * 과목자료함의 **[⭐ 나만의 오답노트]**에 영구 보관되어 시험 전 나만의 비밀 족보로 집중 복습할 수 있습니다.
* **🏠 복습의 집 (취약점 자동 수집)**:
  * 시험에서 틀린 문제는 메인 화면의 **[🏠 복습의 집]**에 자동으로 누적됩니다.
  * 언제든 원클릭으로 틀린 문제들만 모아 재시험을 치를 수 있습니다.

* 내 누적 지식의 빈틈을 완벽히 메우고 다음 학습 단계로 도약하세요.

### 7️⃣ 100% 로컬 프라이버시 & 기기 변경 백업/복원
* **💾 전체 백업**:
  * 설정 화면에서 **[데이터 백업]**을 누르면 내가 만든 과목, 단원, 누적 문제은행 전체가 1장의 텍스트 코드로 복사됩니다. 카카오톡 '나와의 채팅'이나 메모장에 붙여넣어 두세요.
* **🔄 즉시 복원**:
  * 스마트폰을 교체하거나 브라우저를 변경해도, 설정 화면의 **[데이터 복원]**에 백업 코드를 붙여넣기만 하면 1초 만에 모든 학습 기록이 완벽 복구됩니다.

## ❓ 자주 묻는 질문 (FAQ)

* **Q. 정말로 평생 무료인가요?**  
  * 네! Google AI Studio에서 제공하는 무료 티어(개인용 API Key)를 사용하므로 서버 비용이나 결제가 일체 발생하지 않습니다.
* **Q. 스마트폰에서도 바로 이용할 수 있나요?**  
  * 네! 앱스토어 설치 없이 스마트폰 브라우저(Safari, Chrome)로 웹 링크에 접속하시면 모바일 앱과 똑같은 100% 풀스크린 반응형 환경으로 이용하실 수 있습니다.
* **Q. 브라우저 쿠키나 캐시를 지우면 데이터가 사라지나요?**  
  * 로컬 브라우저 저장소를 사용하므로, 중요한 시험 데이터는 설정 화면의 **[데이터 백업]** 기능을 통해 백업 코드를 메모장에 보관해 두시는 것을 권장합니다.
