# 🌸 Celueste (셀루에스테) — 초경량 로컬 퍼스트 AI 맞춤형 CBT 학습 플랫폼

> **"중앙 서버 없이, 내 스마트폰이 전용 서버가 되는 완전한 독립형 AI 학습 파트너"**  
> 사용자의 개인 Google Gemini API를 활용하여 서버 유지비 0원으로 나만의 맞춤형 실전 문제를 출제하고, 오답 개념을 완벽하게 마스터합니다.

---

## 🏛️ 왜 중앙 서버가 없는 초경량 로컬 퍼스트인가요?

일반적인 앱은 모든 데이터가 개발자의 중앙 서버(AWS/GCP)에 모여 서버 비용이 발생하고 서버가 다운되면 앱이 멈추지만, **Celueste는 사용자의 기기 자체가 전용 독립 서버이자 데이터베이스 역할**을 수행합니다.

1. **서버 유지비 평생 0원 (Zero Server Cost)**
   - 개발자도 사용자도 매달 나가는 서버/클라우드 DB 비용이 전혀 없습니다.
2. **중계자 없는 다이렉트 AI 통신 (Direct Client-to-Gemini)**
   - 사용자 기기에서 Google AI(Gemini 2.5/3.5 Flash)로 직접 통신하므로 응답 속도가 매우 빠르고 개인정보와 API Key가 외부에 노출되지 않습니다.
3. **사진 1장보다 가벼운 초경량 데이터 (Ultra-Lightweight Storage)**
   - 모든 문제는 순수 텍스트(JSON)로 저장됩니다.
   - 문제 1,000개 + 풀이 기록 5,000개를 쌓아도 **고작 3~5 MB** 수준(스마트폰 사진 1장 크기)에 불과하여 기기 용량을 전혀 차지하지 않습니다.
4. **스마트폰이 멋대로 지우지 않는 영구 보존 (Persistent Storage)**
   - OS가 임의로 삭제하는 임시 캐시 영역이 아닌, 안전한 로컬 영구 영역(`AsyncStorage`/`Document`)에 저장되어 내 공부 기록이 안전하게 보호됩니다.

## ✨ 핵심 기능

### 1. 🚀 Google Gemini 맞춤형 실전 CBT 문제 출제
- 원하는 과목, 단원, 키워드를 입력하면 AI가 **4지선다형 실전 시험 문제**를 즉시 출제합니다.
- 허위 사실(환각) 없는 신뢰도 높은 교육/학술 팩트를 기반으로 지문, 정답, 상세 풀이, 오답 함정 분석까지 원스톱 생성됩니다.

### 2. 💡 오답 문제 다시 풀기 & 4단계 핵심 개념 복습
- 틀렸던 문제들을 AI 대기 없이 **1초 만에 즉시 다시 풀이**할 수 있습니다.
- 풀이 완료 후 제공되는 4단계 집중 해설지:
  - ❌ **내가 선택한 오답 분석**: 내가 고른 보기가 왜 오답이었는지 원인 규명
  - 📖 **오답 극복 핵심 개념 정리**: 해당 문제의 배경 지식과 용어 정의를 핑크 카드로 확실하게 노출
  - 🔍 **개념 고정 및 오답 방지 팁**: 실전에서 헷갈리지 않게 해주는 원리 팁 제공
  - 💡 **정답 및 문제 풀이**: 정답에 대한 명쾌한 해설

### 3. ⏰ 평일(월~금) 오전 8시 / 저녁 8시 정기 학습 알람
- `expo-notifications` 기반으로 평일 **오전 08:00** 및 **저녁 20:00**에 스마트폰 푸시 알람이 자동 발송됩니다.
- 스마트폰 상단 알람을 터치하면 앱이 열리면서 **즉시 CBT 실전 문제 풀이로 직행**합니다.
- 앱 사용 중에도 해당 시간대가 되면 인앱 알림 팝업으로 [지금 문제 풀기]를 바로 시작할 수 있습니다.

### 4. 🌿 라이프스타일 학습 요일 루틴 설정
- 주 3일(월/수/금), 주 5일(평일), 매일 등 나의 생활 패턴에 맞춰 학습 요일을 선택할 수 있습니다.
- 쉬는 날에는 스트레스 없는 휴식 모드로 자연스럽게 전환됩니다.

### 5. 🛡️ 컴팩트 데이터 백업 & 모바일 원클릭 공유 (`Share.share`)
- 설정 화면의 컴팩트한 미니 버튼(`[💾 백업]`, `[🔄 복원]`, `[🗑️ 초기화]`) 지원.
- 외계어 텍스트를 복사할 필요 없이, **[💾 백업]** 클릭 한 번으로 **카카오톡, 메모장, 파일 저장, 이메일**로 1초 만에 안전하게 내보낼 수 있습니다.
- 새 스마트폰으로 바꾸거나 복구할 때도 보관해둔 텍스트를 붙여넣고 **[복원 실행]**만 누르면 즉시 복구됩니다.

## 📦 배포 및 설치 방법

중앙 서버 구축이 필요 없으므로 배포 대상에 따라 파일 하나만 전달하면 됩니다:

### 📱 1. 안드로이드 스마트폰 배포 (.apk)
스토어 심사 없이 지인이나 테스터에게 직접 전달할 수 있습니다:
```bash
cd apps/mobile
npx eas build -p android --profile preview
```
- 생성된 **`Celueste.apk` 파일**을 카카오톡이나 구글 드라이브로 보내면, 받는 사람이 터치 한 번으로 즉시 설치하여 평생 사용할 수 있습니다.

### 💻 2. 윈도우 PC 프로그램 배포 (.exe)
브라우저 없이 바탕화면에서 더블클릭하여 바로 실행하는 단일 프로그램:
- `npx expo export -p web`으로 웹 번들을 생성한 후, Electron 패키징을 통해 **`Celueste_Setup.exe`**로 배포 가능.

### 🌐 3. 100% 무료 웹 배포 (Vercel / Cloudflare)
- 빌드된 `dist` 폴더를 Vercel이나 Cloudflare Pages에 업로드하면 링크 하나로 어디서나 로그인 없이 즉시 접속 가능 (월 비용 0원).

### 🏪 4. 구글 플레이스토어 / 애플 앱스토어 정식 배포
```bash
npx eas build -p all --profile production
```
- 생성된 번들 파일(`.aab`, `.ipa`)을 구글 플레이 콘솔 및 애플 앱스토어 커넥트에 등록하여 정식 배포.

## 🏃 로컬 개발 및 실행

프로젝트 루트 폴더에서 아래 배치 파일을 실행하세요:

```bash
# 윈도우 원클릭 실행
run_mobile.bat
```
- 콘솔에서 `w` 키를 눌러 웹 브라우저에서 바로 테스트하거나,
- 스마트폰의 Expo Go 앱으로 화면의 QR 코드를 스캔하여 실시간으로 실행할 수 있습니다.
