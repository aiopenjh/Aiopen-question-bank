# Celueste v2.3.2

사용자가 자신의 API 키를 연결해 원하는 주제로 문제를 만들고, 저장한 문제를 반복해서 풀며, 정해 둔 시간에 학습 알림을 받을 수 있는 로컬 퍼스트 CBT 문제은행입니다.

- 웹 서비스: [https://aiopenjh.github.io/Aiopen-question-bank/](https://aiopenjh.github.io/Aiopen-question-bank/)
- 저장소: [https://github.com/aiopenjh/Aiopen-question-bank](https://github.com/aiopenjh/Aiopen-question-bank)
- 기술 스택: React Native, Expo Web, TypeScript, IndexedDB(Web), AsyncStorage(Native)

![Celueste v2 코드 전체 진행 방향](docs/assets/celueste-v2-code-direction.svg)

상세 구조와 실행 순서는 [Celueste v2 아키텍처와 워크플로](docs/ARCHITECTURE_WORKFLOW_V2.md)에서 확인할 수 있습니다.

## v2.3.2 핵심 동작

### 자유 주제 출제

- 자격증, 언어, 게임 입문, 동식물 등 사용자가 지정한 주제를 그대로 학습 대상으로 사용합니다.
- 희귀한 주제라는 이유만으로 다른 주제로 바꾸지 않습니다.
- 무의미한 입력이나 주제 간 충돌이 의심될 때는 대주제와 실제 학습 의도를 함께 확인해 엉뚱한 문제 생성을 줄입니다.
- AI가 직접 문제를 생성하며, 외부 문제은행을 수집하거나 복사하는 방식이 아닙니다.

### 세분화된 난이도

- 시작 난이도를 레벨 1부터 30까지 선택할 수 있습니다.
- 첫 출제는 과목의 시작 레벨을 사용합니다. 이후 레벨 변경은 각 단원에 독립 저장되며 앱을 다시 열거나 백업을 복원해도 유지됩니다.
- 레벨 변경 시 `기존문제유지 + 레벨변경` 또는 `기존문제삭제 + 레벨변경`을 선택합니다. 삭제는 새 문제 저장이 성공할 때만 해당 단원의 이전 문제에 적용됩니다.
- 레벨 31 이상도 계속 확장할 수 있습니다.
- 숫자가 한 단계 오를 때 선행지식과 사고 부담이 조금씩 증가하도록 출제 지시를 구성합니다.
- 정답률만으로 사용자의 레벨을 임의 변경하지 않습니다. 문제 추가 생성과 다음 단원 진행은 사용자가 결정합니다.

### 문제 생성과 검증

- 모든 문제는 `1, 2, 3, 4` 형식의 4지선다입니다.
- 기존 저장 문제와 새 문제의 유사도를 비교해 중복 출제를 줄입니다.
- 보기 중복, 정답 불일치, 빈 지문·해설 등 잘못된 응답을 검사합니다.
- 생성 취소 시 진행 중인 API 요청을 중단하고 추가 생성을 막습니다.
- `429` 요청 한도 응답에는 대기 시간을 적용해 같은 요청이 연속 호출되지 않도록 합니다.
- 동일한 출제 요청이 동시에 들어오면 하나의 진행 중 요청을 공유해 API 중복 호출을 막습니다.
- 응답이 없거나 실패하면 완료로 표시하지 않고 사용자가 이해할 수 있는 오류 안내를 표시합니다.
- AI 전송 오류의 상세 원문은 내부 기록에만 남기고 사용자 안내에는 API 키나 공급자 응답을 노출하지 않습니다.

### 최신 세율·법령 출제

- 세율, 세금, 부동산 법·정책, 법령처럼 변경 가능성이 큰 주제는 출제 시 Gemini의 Google 검색 근거 기능을 사용합니다.
- 국가법령정보센터, 국세청, 기획재정부, 국토교통부, 행정안전부 등 허용된 정부 공식 출처만 문항 근거로 인정합니다.
- 문항에 대한민국 기준일, 현재 시행 상태, 공식 기관·문서·원문 URL을 저장하며 풀이 결과와 문제 보관함에서 확인할 수 있습니다.
- 검색 근거 또는 공식 출처를 확인하지 못하면 문항을 저장하지 않고 실패 이유를 안내합니다.
- 사용자가 연결한 PDF가 있으면 PDF 제한 출제 원칙을 우선하며 자동 웹 검색을 섞지 않습니다.

### Gemini 모델 기준

- 기본 모델은 `gemini-3.5-flash`입니다.
- Gemini 자동 전환은 3.5 이상 후보 안에서만 수행합니다.
- 저장된 이전 설정이 3.5 미만이면 실행 시 3.5 기준으로 보정합니다.
- 모델명은 일반 사용자 화면에 별도 상태로 노출하지 않습니다.

### 학습 흐름과 데이터

- 과목 등록 시 시작 레벨을 기준으로 첫 5개 단원을 구성합니다.
- 사용자는 이후 단원을 5개씩 추가하며 학습 범위를 계속 넓힐 수 있습니다.
- 생성한 문제, 풀이 기록, 오답, 과목과 단원은 사용자 기기에 저장됩니다.
- 웹에서는 처음 실행할 때 개인 IndexedDB를 자동 생성하고 기존 브라우저 저장 데이터를 검증 후 자동 이관합니다. 사용자가 별도로 DB를 만들 필요가 없습니다.
- IndexedDB 이관에 실패하면 기존 저장소를 유지하며, API 키는 일반 학습 데이터와 분리된 보안 저장소에 둡니다.
- 자료함 첫 화면은 과목 목록을 먼저 보여주고, 과목을 열면 해당 과목의 단원만 표시합니다.
- 문제 보관함은 과목 상세 밖에서 전체 과목·단원을 기존 방식으로 관리합니다.
- 단원 삭제는 해당 단원과 연결된 문제를 함께 삭제하며 복구할 수 없음을 확인창에서 알립니다.
- 전체 과목 삭제는 과목 카드 상단의 관리 영역에서 실행할 수 있어 문제 목록이 길어져도 아래로 스크롤할 필요가 없습니다.
- 백업 ZIP/JSON에는 API 키를 제외한 학습 데이터가 포함되며, 복원 전 형식을 검사하고 저장 실패 시 기존 데이터 복구를 시도합니다.
- 전체 데이터 초기화는 IndexedDB, 이전 저장 데이터와 API 키를 삭제합니다. 추후 복구가 필요하면 초기화 전에 백업해야 합니다.
- **+ 자료**에서 PDF 또는 텍스트를 등록하고, **자료함 → 과목 추가 → 내 파일 불러오기**에서 자료를 과목에 연결할 수 있습니다.
- PDF 페이지 수 확인과 페이지 분할은 기기 안에서 처리합니다. PDF 원본과 전체 본문은 IndexedDB·백업에 저장하지 않으며, 선택한 페이지는 목차나 문제를 생성할 때만 Gemini 요청에 포함됩니다.
- 큰 PDF는 10~20페이지씩 나누고 문제는 한 번에 3~5문항씩 생성하도록 안내합니다. 하루 누적 15문항을 넘기면 무료 할당량과 429 가능성을 알리고 추가 진행 여부를 확인합니다.

### 알림과 재방문

- 사용자가 선택한 요일과 아침·저녁 시간에 로컬 학습 알림을 예약합니다.
- 알림을 누르면 앱으로 이동하며, 특정 단원을 자동 선택하거나 바로 문제를 시작하지 않습니다.
- 사용자가 과목과 단원을 직접 고른 뒤 문제를 출제합니다.

### 설치형 웹 경험

- Android Chrome과 iOS Safari에서 홈 화면에 추가할 수 있습니다.
- 웹 앱 매니페스트, Android용 192/512px 아이콘, Apple Touch 아이콘과 파비콘을 제공합니다.
- 기존 홈 화면 바로가기의 아이콘은 운영체제 캐시 때문에 삭제 후 다시 추가해야 바뀔 수 있습니다.

### 학습 화면과 대기 경험

- 메인·자료함·설정 탭의 너비와 전환 동작을 맞춰 화면 이동을 부드럽게 유지합니다.
- 일일 목표는 가운데 문항 조절과 같은 카드 안의 저장 버튼으로 관리합니다.
- AI 문제·목차 생성 중에는 네 장의 캐릭터 동작을 가볍게 연결해 대기 피로를 줄입니다.
- 모션 감소 접근성 설정이 켜진 기기에서는 캐릭터 동작을 멈춥니다.
- 메인 화면의 응원 영역은 `당신을 위한 Celueste의 한마디`로 표시합니다.

## 사용 방법

1. Google AI Studio에서 사용할 API 키를 준비합니다.
2. Celueste의 **설정**에서 API 키를 저장합니다.
3. **과목자료함 → 새 과목 추가**에서 자유롭게 학습 주제를 입력합니다.
4. 시작 레벨을 선택하고 과목과 첫 5개 단원을 생성합니다.
5. 원하는 단원의 **출제 / 풀기**를 눌러 문항 수와 난이도를 확인한 뒤 문제를 만듭니다.
6. CBT에서 답을 선택하고 제출하면 결과와 해설을 확인할 수 있습니다.
7. 설정에서 학습 알림과 백업을 관리합니다.

API 사용량과 사용 가능 모델은 사용자가 연결한 API 제공자의 계정, 지역, 할당량 정책을 따릅니다.

## 문의

설정 하단의 **의견 보내기**에서 앱 내부 입력창으로 내용을 작성합니다. 작성한 의견만 Formspree를 통해 관리자에게 전송하며 학습 데이터와 API 키는 첨부하지 않습니다. 중복 전송을 막고, 20초 동안 응답이 없으면 입력 내용을 보존한 채 안내하고 다시 창을 닫을 수 있게 합니다.

## 개발과 검증

```powershell
cd apps/mobile
npm install

# 타입 검사
.\node_modules\.bin\tsc.cmd --noEmit

# 자동 회귀 테스트
node --test tests/*.test.cjs

# 로컬 웹 실행
npm run web

# 웹 배포 번들 생성
npx expo export -p web --clear
```

GitHub Pages 배포:

```powershell
# 저장소 루트에서 실행
powershell -ExecutionPolicy Bypass -File .\deploy-gh-pages.ps1
```

배포 스크립트는 `buildInfo.ts`에서 버전 정보를 읽어 `version.json`을 만들고, Expo 웹 번들을 생성한 뒤 `gh-pages` 브랜치에 게시합니다.

## 주요 구조

```text
Aiopen-question-bank/
├── README.md
├── deploy-gh-pages.ps1
└── apps/mobile/
    ├── App.tsx
    ├── app.json
    ├── public/                  # manifest, version, 설치 아이콘
    └── src/
        ├── components/          # 앱 화면과 공통 UI
        ├── data/                # 로컬 저장소와 repository
        ├── domain/              # 출제 의도, 난이도, 생성, 중복 검사, AI 통신
        ├── features/            # 학습, 자료함, 시험, 설정
        ├── hooks/               # 화면 동작과 생성 흐름
        └── utils/               # 알림, 백업, 시험지 출력
```

## 배포 버전

- 앱 버전: `2.3.2`
- Android `versionCode`: `6` (이번 배포는 웹)
- 웹 버전 확인 파일: `apps/mobile/public/version.json`
