# Celueste — 나만의 AI 학습 문제은행

Celueste는 원하는 과목과 난이도를 정하면 AI가 학습 목차와 문제를 만들고, 문제 풀이·해설·오답 복습까지 이어주는 로컬 퍼스트 학습 서비스입니다.

- 웹 서비스: [Celueste 바로가기](https://aiopenjh.github.io/Aiopen-question-bank/)
- 개발자·관리자 문서: [DEVELOPER.md](DEVELOPER.md)
- 변경 이력: [CHANGELOG.md](CHANGELOG.md)

## 시작하기

1. Celueste를 열고 상단의 `+ 자료` 또는 메인의 `새 주제로 학습하기`를 누릅니다.
2. 과목 이름, 분류, 시작 난이도를 정해 학습 과목을 만듭니다.
3. 설정의 `AI 연결`에서 사용할 API 키를 등록합니다.
4. 생성된 단원에서 새 문제를 만들거나, 저장된 문제로 바로 시험을 시작합니다.

API 키가 없으면 가짜 문제를 대신 보여주지 않습니다. 연결이 필요한 상태를 안내하고, 키를 등록한 뒤 실제 AI 출제를 진행합니다.

## 주요 화면

### 메인 — 오늘의 학습

- 진행 중인 과목, 오늘 풀이 수, 일일 목표 달성률을 한 화면에서 확인합니다.
- `이어서 학습하기`로 최근 학습 흐름을 바로 계속합니다.
- `새 주제로 학습하기`에서 새로운 과목과 목차를 만듭니다.
- 응원 문구, 복습 예정 문항, 나만의 오답노트를 함께 확인합니다.

### 자료함 — 과목과 문제 보관

- 과목 목록과 단원별 저장 문제를 한 화면에서 관리합니다.
- 저장된 문제가 있는 단원은 `기존 문제 풀기`로 AI 호출 없이 바로 시험을 시작합니다.
- `새 문제 만들기`로 같은 단원에 새로운 문제를 추가합니다.
- 과목 전체의 저장 문제를 모아 CBT 시험으로 풀 수 있습니다.
- 교재·요약 자료를 연결하면 해당 내용과 용어를 우선 반영해 출제합니다.

### 설정 — 필요한 항목만 펼쳐서 관리

- 일일 학습 목표는 화살표로 변경하면 즉시 저장됩니다.
- 알람 설정, AI 연결, 데이터 관리는 필요한 항목만 눌러 펼칠 수 있습니다.
- 사용설명서는 설정 화면 오른쪽 위에서 열 수 있습니다.
- 앱 버전과 갱신 버튼은 설정 화면 맨 아래에서 확인합니다.

## 학습 알람

- 오전·저녁으로 구분하지 않고 원하는 시각을 직접 등록합니다.
- `07:20`, `13:00`, `22:15`처럼 분 단위까지 설정할 수 있습니다.
- 최대 8개의 알람 시간을 추가하고 개별적으로 수정하거나 삭제할 수 있습니다.
- 선택한 요일 전체에 등록된 시간들이 공통 적용됩니다.
- 이전 버전의 오전·저녁 알람과 단일 알람 설정은 새 다중 알람 형식으로 자동 변환됩니다.

> 웹 알림은 브라우저 권한과 실행 상태의 영향을 받습니다. 앱이나 웹페이지가 완전히 종료된 상황의 안정적인 예약 알림은 모바일 네이티브 환경을 권장합니다.

## 문제 풀이와 복습

- 새 문제를 만들 때 각 문항 유형을 객관식·주관식·빈칸형 중 독립적으로 무작위 추첨합니다. 문항 수에 맞춰 비율을 강제로 고정하지 않으므로 3문제가 모두 같은 유형으로 나올 수도 있습니다.
- 주관식이 추첨되면 단답형과 서술형 중 하나를 다시 무작위로 정합니다. 낮은 난이도에서도 현재 학습 수준에 맞춘 짧은 주관식이 출제될 수 있습니다.
- 객관식 정답 위치와 전체 문제 순서도 코드 수준에서 무작위로 분산합니다.
- 객관식은 보기를 선택하고, 단답형·서술형은 답안을 직접 입력하며, 빈칸형은 표시된 각 빈칸에 답을 작성합니다.
- 시험 제출 후 정답, 직접 작성한 답안, 채점 결과, 핵심 개념과 해설을 확인합니다. 빈칸형은 기기에서 즉시 채점하고 단답형·서술형은 연결된 AI가 모범답안과 채점 기준에 따라 판정합니다.
- 틀린 문제는 복습 대상으로 모이고, 필요한 문제는 오답노트에 보관합니다.
- 기존 문제에 저장된 힌트가 없으면 사용자가 요청할 때만 AI 힌트를 생성하며, 생성된 힌트는 다시 사용할 수 있도록 저장합니다.
- 분수, 제곱근, 위·아래 첨자, 시그마, 적분, 그리스 문자 등 자주 쓰는 수학 표기를 화면에서 읽기 쉽게 표시합니다.

### 풀이공간

- 시험 상단의 `풀이공간`에서 마우스나 손가락으로 계산과 메모를 자유롭게 적을 수 있습니다. 작성 내용은 답안과 채점에 포함되지 않습니다.
- `↶ 되돌리기`는 마지막 한 획만 지우고, `전체 지우기`는 현재 그림을 모두 지웁니다.
- 다른 문제로 이동하면 풀이공간이 닫히고 그림이 초기화됩니다.
- 풀이공간을 닫았다가 같은 문제에서 다시 열면 작성 중인 그림은 유지됩니다.

## 데이터와 개인정보

- 과목, 단원, 문제, 풀이 기록은 사용자의 기기에 저장됩니다.
- 웹에서는 IndexedDB, 모바일에서는 AsyncStorage를 사용합니다.
- API 키는 일반 학습 백업에 포함하지 않습니다.
- 설정의 `데이터 관리`에서 ZIP 백업, 복원, 인쇄용 문제지·해설지·오답노트를 관리할 수 있습니다.
- 브라우저 데이터 삭제나 기기 변경 전에 반드시 백업 파일을 보관해 주세요.

## 지원하는 AI 연결

등록한 키 형식에 따라 Google Gemini, Anthropic Claude, OpenAI 연결을 구분합니다. 실제 사용 가능 모델과 무료 사용량은 각 제공사의 정책에 따라 달라질 수 있습니다.

## 자주 묻는 질문

### 앱을 설치해야 하나요?

웹 브라우저에서 바로 사용할 수 있습니다. 모바일 화면에도 맞춰져 있으며, 네이티브 빌드에서는 로컬 예약 알림을 사용할 수 있습니다.

### 같은 과목에 문제를 계속 추가할 수 있나요?

가능합니다. 기존 문제는 보존하면서 새 문제를 누적할 수 있으며, 저장 문제만 다시 풀 수도 있습니다.

### 원하는 문제 유형만 선택할 수 있나요?

현재는 새 문제를 만들 때 문항마다 유형을 자동으로 무작위 추첨합니다. 객관식·주관식·빈칸형이 연속되거나 전부 같은 유형으로 나올 수 있으며, 사용자가 특정 유형을 고정하는 설정은 아직 제공하지 않습니다.

### API 키도 백업되나요?

아닙니다. 보안을 위해 일반 학습 백업에서 제외됩니다. 복원 후 설정에서 다시 등록해야 합니다.

### 데이터는 서버에 저장되나요?

기본 학습 데이터는 사용자의 기기에 저장됩니다. 랭킹처럼 별도 네트워크 기능을 사용하는 경우에는 해당 기능에 필요한 최소 정보만 별도 정책에 따라 처리합니다.
