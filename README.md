# 🌸 Celueste (셀루에스테) — 초경량 로컬 퍼스트 AI 맞춤형 CBT 학습 플랫폼

> **"중앙 서버 없이, 내 스마트폰이 전용 서버가 되는 완전한 독립형 AI 학습 파트너"**  
> 사용자의 개인 Google Gemini API를 활용하여 서버 유지비 0원으로 나만의 맞춤형 실전 문제를 출제하고, 오답 개념을 완벽하게 마스터합니다.

---

## 🏛️ 제품 철학 및 핵심 아키텍처 (Philosophy & Architecture)

Celueste는 사용자의 학습 주권을 완전히 보장하기 위해 **로컬 퍼스트(Local-First)** 원칙으로 설계되었습니다.

### 1. 0원 서버 유지비 & 영구 소장 (Zero Server Cost & Self-Sovereignty)
- 개발자의 중앙 서버(AWS/GCP/Supabase 등)에 종속되지 않습니다.
- 서비스가 종료되거나 서버 점검 중이어도, 스마트폰에 설치된 앱과 학습 데이터는 평생 안전하게 작동합니다.

### 2. 100% 프라이버시 보호 & 제로 지식 암호화 (Zero-Knowledge Privacy)
- 나의 학습 기록, 오답 노트, 그리고 **Google Gemini API Key**는 외부 서버를 단 1Byte도 거치지 않습니다.
- 사용자의 기기에서 Google AI로 직접 통신(Direct Client-to-Gemini)하며, API 키는 화면에 텍스트로 노출되지 않는 **블라인드 보안 설계**가 적용되어 있습니다.

### 3. 사진 1장보다 가벼운 초경량 데이터 (Ultra-Lightweight Storage)
- 모든 문제는 군더더기 없는 순수 JSON 규격으로 저장됩니다.
- 문제 1,000문항과 풀이 기록 5,000건을 축적해도 데이터 크기는 **단 3~5 MB**(스마트폰 사진 1장 크기)에 불과합니다.
- OS가 임의로 비우는 임시 캐시가 아닌 **로컬 영구 스토리지(`AsyncStorage`)**에 안전하게 보존됩니다.

### 4. 서버 없는 무선 업데이트 & 완벽한 데이터 보존 (Zero-Server OTA & Data Safety)
- 중앙 서버가 없어도 **Expo EAS 무선 업데이트(OTA)**를 통해 버그 수정과 화면 개선을 실시간으로 배포할 수 있습니다.
- 고정된 안드로이드 패키지명(`com.celueste.app`)을 통해 새로운 APK로 판올림하더라도 **기존 학습 기록, 푼 문제, 맞춤 설정이 100% 유지**됩니다.

## ✨ 주요 핵심 기능

### 1. ⚡ AI 즉시 문제 출제 & 커리큘럼 생성
- **개념 즉시 출제**: 메인 화면에서 키워드(예: `FastAPI 의존성 주입`, `SQL 인덱스 원리`)를 입력하면 Google Gemini가 즉시 4지선다 실전 문제를 생성합니다.
- **5단계 마이크로 커리큘럼**: 새로운 과목 등록 시 학습 단계가 체계적으로 자동 수립됩니다.

### 2. 📝 실전 CBT 시험 & 4단계 오답 극복 멘토링
- **실전 모의고사**: 실제 자격증/공기업 CBT 시험과 동일한 인터페이스로 타이머와 함께 문제를 풀이합니다.
- **4단계 집중 해설지**:
  - ❌ **내가 선택한 오답 분석**: 왜 그 보기를 골랐는지 함정과 오개념 분석
  - 📖 **핵심 개념 정리**: 배경 지식과 표준 용어 정의 카드
  - 🔍 **오답 방지 팁**: 실전에서 헷갈리지 않는 판별 원리
  - 💡 **정답 및 명쾌한 해설**: 정답 도출 과정 상세 설명

### 3. 🎯 일일 학습 목표 맞춤 설정
- 설정 화면의 `🎯 일일 학습 목표 설정`에서 숫자 직접 입력, `◀`/`▶` 증감 버튼, 또는 프리셋 칩(`3`, `5`, `10`, `15`, `20` 문제)을 통해 목표치를 자유롭게 변경할 수 있습니다.
- 홈 화면의 메인 프로그레스 바(예: `1 / 3 완료 (33%)`)와 실시간 동기화됩니다.

### 4. ⏰ 스마트 정기 학습 알람 (주 7일 원터치)
- `[월] [화] [수] [목] [금] [토] [일]` 개별 원터치 토글로 나만의 루틴을 설정합니다.
- 스마트폰 상단 알림을 터치하면 **앱 실행과 동시에 즉시 문제 풀이로 직행**합니다.

### 5. 🔒 블라인드 API Key 보안 시스템
- 화면에 실제 API 키 문자열이 일체 렌더링되지 않는 슬림형 프라이버시 카드로 재설계되었습니다.
- 등록 시 암호화 보관되며, 언제든지 키 수정 및 안전한 삭제가 가능합니다.

### 6. 📚 과목 보관함 및 안전한 데이터 관리
- 과목 삭제 시 `[🗑️ 과목 전체 삭제]` 경고 알럿으로 실수에 의한 데이터 삭제를 방지합니다.
- **[💾 백업]**: 카카오톡, 이메일, 메모장 등으로 내 모든 학습 데이터를 1초 만에 JSON 텍스트로 내보내기(`Share.share`).
- **[🔄 복원]**: 폰을 교체하거나 재설치했을 때 백업 코드를 붙여넣어 완벽 복구.

## 📱 사용자 이용 가이드 (How to Use)

### 1단계: 앱 시작 및 무료 Gemini API Key 발급
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 구글 계정으로 로그인하여 무료 API Key를 발급받습니다. (신용카드 등록 없이 무료 티어 이용 가능)
2. 앱 우측 상단 **⚙️ 설정** 버튼을 눌러 발급받은 API 키를 붙여넣고 **[저장]**합니다.

### 2단계: 첫 문제 풀기
- **기본 과목 풀기**: 메인 화면에 준비되어 있는 **"Python 비동기 프로그래밍"**의 [오늘의 문제 풀기]를 눌러 3문제를 바로 풀어봅니다.
- **새로운 문제 출제**: 메인 화면 상단의 **"⚡ AI 즉시 문제 출제"** 입력창에 공부하고 싶은 주제를 넣고 [출제]를 누릅니다.

### 3단계: 복습 및 루틴 형성
- 문제를 풀고 나면 **"복습의 집"**에 취약 문제가 자동으로 누적되며, 오답 노트를 통해 언제든 1초 만에 재시험을 치를 수 있습니다.

## 🛠️ 개발자 배포 및 유지보수 가이드 (Zero-Server Ops)

### 1. 로컬 개발 환경 실행
```bash
# 저장소 클론
git clone https://github.com/aiopenjh/Aiopen-question-bank.git
cd "Aiopen-question-bank"

# 모바일 앱 의존성 설치 및 실행
cd apps/mobile
npm install
npm start
```
- 터미널에서 `a`(Android)를 누르거나, 스마트폰의 **Expo Go** 앱으로 QR 코드를 스캔하여 실시간 개발.

### 2. 안드로이드 직접 설치용 APK 파일 빌드 (.apk)
스토어 심사 없이 테스터나 지인에게 공유할 수 있는 순수 `.apk` 파일을 Expo 클라우드에서 빌드합니다:

```bash
cd apps/mobile

# 1. EAS CLI 로그인 (Expo 계정 필요, 무료)
npx eas-cli login

# 2. APK 빌드 실행 (eas.json preview 프로필에 buildType: apk 설정 완료)
npx eas-cli build -p android --profile preview
```
- 빌드 완료 후 터미널에 생성되는 **다운로드 링크(URL)**에서 `.apk` 파일을 받아 배포합니다.
- 동일한 패키지명(`com.celueste.app`)이므로, 업데이트 설치 시 사용자의 기존 데이터는 안전하게 보존됩니다.

### 3. 무선 자동 업데이트 배포 (서버 없이 실시간 코드 반영!)
사용자에게 새 APK를 다시 다운받게 하지 않고, UI 수정 및 버그 패치를 무선으로 배포할 때:

```bash
cd apps/mobile
npx eas-cli update --branch production
```
- 사용자가 다음번에 앱을 켤 때 백그라운드에서 변경 사항을 자동으로 다운로드받아 새 버전으로 적용됩니다.

## 📂 프로젝트 아키텍처

```
AI-powered test generator app/
├── README.md                           # 프로젝트 가이드 (본 문서)
├── run_mobile.bat                      # 원클릭 윈도우 실행 스크립트
├── docs/                               # 아키텍처 및 상세 명세 문서
└── apps/
    └── mobile/
        ├── App.tsx                     # 메인 화면 조율 및 라우팅 (500라인 준수)
        ├── app.json                    # Expo 앱 설정 (패키지명: com.celueste.app)
        ├── eas.json                    # APK 클라우드 빌드 프로필
        └── src/
            ├── components/             # 공용 헤더 및 팝업 모달
            ├── contracts/              # TypeScript 타입 명세 (types.ts)
            ├── data/                   # 영구 저장소 (db.ts, storage_keys, 리포지토리)
            ├── domain/                 # AI 클라이언트, 출제 엔진, 루틴/배분 알고리즘
            ├── features/
            │   ├── study/              # 메인 학습 맵 화면 (StudyMapScreen)
            │   ├── library/            # 과목 보관함 & 복습의 집 (LibraryScreen)
            │   ├── exam/               # 실전 CBT 풀이 및 4단계 해설지 (ExamScreen)
            │   └── settings/           # 설정, 알람, 일일목표, API키, 백업 화면
            ├── hooks/                  # 비즈니스 로직 훅 (useAppData, useQuizGeneration 등)
            └── utils/                  # 알람(notifications), 알럿(alert)
```
