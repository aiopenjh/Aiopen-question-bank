## 📖 실사용 가이드 (Step-by-Step User Manual)

### 1단계: 1분 만에 무료 Gemini API 키 등록하기
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에 구글 계정으로 로그인하여 무료 API Key를 발급받습니다. (신용카드 등록 없이 평생 무료 티어로 이용 가능)
2. Celueste 우측 상단의 **⚙️ 설정** 아이콘을 누릅니다.
3. 발급받은 API 키를 붙여넣고 **[저장]**을 누릅니다. (키는 외부 서버로 전송되지 않고 본인 기기 로컬 스토리지에만 암호화 보관됩니다.)

---

### 2단계: 새 학습 과목 추가 & AI 목차 자동 구성
1. 메인 화면의 **[📚 과목자료함]** 버튼을 터치합니다.
2. 상단의 **[+ 새 과목 추가]** 버튼을 누릅니다.
3. 과목 정보를 입력합니다:
   - **🏷️ 과목 이름 (대주제)**: 공부하고 싶은 핵심 과목을 입력합니다. (예: `정보처리기사`, `법학개론`, `바람의나라`, `토익 보카`, `회계원리` 등)
   - **📂 과목 분류 (소주제/카테고리)**: 세부 학습 영역을 직접 입력하거나 하단 추천 칩(`⚖️ 법학`, `🎮 게임/개발`, `💼 비즈니스`, `🌐 어학` 등)을 선택합니다.
   - **🌱 학습자 수준 선택**: 🐣 왕초보입문 / 🌿 기본기보유 / 🚀 실전시험대비 / 👑 심화킬러 중 본인 수준 선택.
4. **[과목 및 목차 자동 생성]**을 누르면, AI가 국가공인 표준 교육과정에 기반하여 **체계적인 5단계 마이크로 소단원 목차**를 5초 만에 자동으로 설계합니다.

---

### 3단계: [선택 꿀팁] 내 교재나 요약 자료 첨부하기
- 내가 가지고 있는 수험서, 수업 필기, PDF 요약본 등의 텍스트가 있다면:
- 과목자료함에서 해당 과목의 **[📖 교재/자료 첨부]**를 눌러 내용을 붙여넣으세요.
- AI가 **학습자가 직접 첨부한 교재 내용과 전문 용어를 100% 최우선 반영**하여 적중률 높은 실전 문제를 정밀 출제합니다.

---

### 4단계: 원하는 단원 터치 ➔ 문항 수 선택 ➔ 실전 CBT 응시
1. 과목자료함에서 풀고 싶은 소단원의 **[문제 출제]** 버튼을 누릅니다.
2. 원하는 문제 수 팝업에서 **[3문항]**, **[5문항]**, **[10문항]**, **[20문항]** 중 원하는 분량을 터치합니다.
3. 5~10초 만에 공인 시험 기준 4지선다 문제가 생성되며, **실전 CBT 시험장**으로 즉시 입장합니다.
4. 실전 시험 모드:
   - 제한 시간 타이머 및 실시간 문항 진행 바 제공
   - 실제 자격증/국가고시 CBT 화면과 동일한 선지 마킹 시스템
   - 언제든지 문제를 풀고 **[시험 제출]**을 누르면 자동 채점 완료

---

### 5단계: 4단계 입체 오답노트 & '복습의 집' 정복
시험을 마치면 단순 정답 공개를 넘어선 **4단계 집중 오답 멘토링**이 제공됩니다:
- ❌ **선택한 오답 분석**: 내가 고른 오답이 왜 정답이 아니며 어떤 함정에 빠졌는지 구체적 해설
- 📖 **핵심 개념 정리**: 해당 문제의 배경 학술 이론과 필수 암기 포인트
- 🔍 **오답 방지 팁**: 실전 시험에서 헷갈리지 않고 정답을 골라내는 판별법
- 💡 **정답 및 명쾌한 도출 과정**: 반박 불가능한 정답 논리

> **취약 문제 자동 보관**: 틀린 문제는 메인 화면의 **[🏠 복습의 집]**에 자동으로 누적되어, 언제든 1초 만에 오답만 모아 재시험을 치를 수 있습니다.

---

### 6단계: 백업과 복원으로 데이터 영구 보존
- **[💾 전체 백업]**: 설정 화면에서 [데이터 백업]을 누르면 내가 만든 과목, 단원, 누적된 문제은행 전체가 1장의 JSON 암호화 코드로 복사됩니다. 카카오톡 나에게 보내기나 메모장에 저장해 두세요.
- **[🔄 데이터 복원]**: 폰을 바꾸거나 브라우저를 변경해도 백업 코드를 붙여넣기만 하면 1초 만에 모든 데이터가 100% 복구됩니다.

## 🏛️ Celueste만의 독보적인 4대 AI 출제 헌법 & 보안 시스템

외부의 악의적인 프롬프트 조작(인젝션)이나 비정상적인 입력에도 절대 흔들리지 않는 **강력한 무결성 엔진**이 탑재되어 있습니다.

### 1. 교차 분야 충돌 예외처리 (Cross-Domain Conflict Resolution)
- **대주제와 소주제가 다른 경우** (예: 대주제 `바람의나라` + 소주제 `바리스타 기초과정`):
  - AI가 엉뚱하게 게임 캐릭터 생성 문제 등을 내지 않고, 학습자가 명시적으로 배우고자 지정한 **실제 세부 학습 대상(`바리스타 커피 지식`)을 최우선 기준으로 채택**하여 출제합니다.

### 2. 엉뚱한 입력/오타 자동 폴백 (Nonsense Fallback)
- 소주제에 장난, 무의미한 자모(`ㅁㄴㅇㄹ`, `asdf`), 일상 대화 등을 입력하더라도:
  - 엉뚱한 소주제는 즉시 무시하고, 정규 학술 체계가 확립된 **본래 대주제(과목명)**를 기준으로 정상 문제를 안전하게 출제합니다.

### 3. 원점 대주제 고정 (Root Domain Anchoring)
- 심화 문제로 깊어질 때 인접한 다른 분야로 탈선하는 현상을 방지합니다.
  - 예: `게임 개발` 과목이 심화되더라도 게임 물리 연산과 데미지 공식으로 심화되며, 현실의 군사 총기 화학 공식으로 왜곡되지 않습니다.

### 4. 정답 위치 균등 무작위 분산 (Fisher-Yates 셔플 엔진)
- *"답은 항상 3번으로 해줘"*와 같은 인위적 프롬프트 조작을 원천 봉쇄합니다.
- AI의 지시와 무관하게 시스템 코드 레벨에서 **수학적 무작위 알고리즘으로 1, 2, 3, 4번에 정답을 완벽히 분산**시키며, 연속 동일 번호 중복을 방지합니다.

## 📱 모바일 웹 최적화 (Mobile Web UX Hardening)

- **입력창 화면 작아짐(Pinch-Zoom) 원천 차단**:
  - 모바일 브라우저(iOS Safari, Android Chrome)가 16px 미만 폰트 터치 시 화면을 강제 확대/축소하는 고질적 버그를 전역 16px 스타일 및 `maximum-scale=1.0, user-scalable=no` 뷰포트 메타태그로 원천 봉쇄했습니다.
  - 스마트폰에서 어떤 입력란을 터치해도 화면 크기와 팝업 배율이 안정적으로 유지됩니다.
- **반응형 모달 & 겹침 없는 독립 스크롤**:
  - 모바일 작은 화면부터 태블릿, 데스크톱 와이드 모니터까지 완벽하게 대응합니다.

## 🛠️ 개발 및 배포 명령어 (Developer Ops)

### 1. 로컬 개발 환경 실행
```bash
# 모바일 앱 디렉토리로 이동
cd apps/mobile

# 패키지 설치
npm install

# 로컬 개발 서버 실행 (웹 & Expo Go)
npm start
# 또는 브라우저 즉시 열기
npm run web
```

### 2. GitHub Pages 원클릭 정적 배포
```powershell
# 프로젝트 루트에서 실행 (빌드, .nojekyll, SPA 404 라우팅, gh-pages 자동 푸시)
powershell -ExecutionPolicy Bypass -File .\deploy-gh-pages.ps1
```

### 3. 안드로이드 APK 파일 빌드 (.apk)
```bash
cd apps/mobile
npx eas-cli login
npx eas-cli build -p android --profile preview
```
